# 2D系统

2D游戏是指二维交互式动画，即2D动画。只不过在游戏方面，此动画可以根据用户需求而进行互动。

## 2D游戏特征

贴图：传统2D游戏中的美术资源（人物行走、人物状态、地图等）都是以png或jpg的图形文件渲染而成，而3D游戏多以模型为主。图形文件在使用之前通常需要切割。

视角：2D游戏无法完成视角转换，因为2D游戏的美术资源是平面图。

渲染：2D游戏的所有美术资源可以不经过引擎渲染直接使用。
