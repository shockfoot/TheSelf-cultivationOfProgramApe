角色结构为：空对象--角色模型。

角色行为脚本挂在空物体上，此类挂在角色的模型对象上（当更改模型时不需要重新挂载角色行为脚本），负责在特定时机取消动画，在特定时机引发事件。使用Unity新版动画系统时使用此类。

``` C#
public class AnimationEventBehaviour : MonoBehaviour
{
    // 策划：为动画片段添加指定事件：停止动画OnCancelAnim、触发攻击OnAttack
    // 程序：在脚本中播放动画，动画中需要执行的逻辑，注册attackHandler事件
    
    private Animator anim;
    // 攻击事件
    public event Action attackHandler;
    
    private void Start()
    {
        anim = GetComponent<Animator>();
    }
    // 由Unity引擎调用
    private void OnCancelAnim(string animParam)
    {
        anim.SetBool(animParam, false);
    }
    // 由Unity引擎调用
    private void OnAttack()
    {
        if (attackHandler != null)
            attackHandler();
    }
}
```
