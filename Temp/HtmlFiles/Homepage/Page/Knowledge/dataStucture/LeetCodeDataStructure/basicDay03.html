1、两个数组的交集

给定两个整数数组nums1和nums2，以数组形式返回两数组的交集。若一个元素每同时在两个数组中都出现一次，则该元素在交集中便出现一次。可以不考虑输出结果的顺序。

解法1：哈希表

通过哈希表存储nums1中重复出现的元素和重复次数。在遍历nums2时，在哈希表中查找该元素。若存在，则在结果中写入该元素，哈希表中的值减一。当哈希表中的值为0时，表明nums1中重复次数小于nums2的，不应写入结果。

为了降低空间复杂度，可以针对长度较小的数组创建哈希表。

public int[] Intersect(int[] nums1, int[] nums2)
{
    Hashtable ht = new Hashtable();
    //遍历nums1，记录重复元素和重复次数
    for (int i = 0; i < nums1.Length; i++)
    {
        if (ht.ContainsKey(nums1[i]))
            ht[nums1[i]] = (int)ht[nums1[i]] + 1;
        else
            ht.Add(nums1[i], 1);
    }
    //不确定结果数组的长度，因此使用List泛型集合来存储
    List list = new List();
    //遍历nums2并查找哈希表
    for (int i = 0; i < nums2.Length; i++)
    {
        //记录结果时应要考虑该元素在两个数组重复次数不一致
        if (ht.ContainsKey(nums2[i]) && (int)ht[nums2[i]] > 0)
        {
            list.Add(nums2[i]);
            ht[nums2[i]] = (int)ht[nums2[i]] - 1;
        }
    }
    return list.ToArray();
}

解法2：双索引

因为结果不考虑输出顺序，可以对两数组进行排序，然后使用双索引依次遍历，写入相同的元素。

public int[] Intersect(int[] nums1, int[] nums2)
{
    Array.Sort(nums1);
    Array.Sort(nums2);
    List list = new List();
    int i = 0, j = 0;
    //当一数组遍历完，另一个数组剩余元素不会出现在此数组中
    while (i < nums1.Length && j < nums2.Length)
    {
        if (nums1[i] == nums2[j])
        {
            list.Add(nums1[i]);
            i++;
            j++;
        }
        else if (nums1[i] < nums2[j])
            i++;
        else
            j++;
    }
    return list.ToArray();
}

2、买卖股票的最佳时机

给定一个数组prices，它的第i个元素prices[i]表示一支给定股票第i天的价格。只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。计算可以获取的最大利润。如果不能获取任何利润，则返回0。

注意：卖出价格需要大于买入价格；不能在买入前卖出股票。

解法1：暴力法

public int MaxProfit(int[] prices)
{
    int maxProfit = 0, n = prices.Length;
    for (int i = 0; i < n - 1; i++)
    {
        for (int j = i + 1; j < n; j++)
        {
            maxProfit = Math.Max(prices[j] - prices[i], maxProfit);
        }
    }
    return maxProfit;
}

解法2：贪心算法

自买入股票后每天计算股票在手的利润，只要不亏损就不卖出，记录此间每天利润的最大值。

public int MaxProfit(int[] prices)
{
    int maxProfit = 0, profit = 0;
    for (int i = 1; i < prices.Length; i++)
    {
        //股票从入手到今天的利润
        profit += prices[i] - prices[i - 1];
        if (profit > maxProfit)
            maxProfit = profit;
        if (profit < 0)
            profit = 0;
    }
    return maxProfit;
}

解法3：动态规划法

f(i)代表第i天的最大利润，那么f(i)与f(i-1)的关系：f(i) = max{f(i-1), prices[i] - minPrice}。因此，通过记录之前minPrice，在之后遍历过程中，更新minPrice，并在计算利润时存储maxProfit。
