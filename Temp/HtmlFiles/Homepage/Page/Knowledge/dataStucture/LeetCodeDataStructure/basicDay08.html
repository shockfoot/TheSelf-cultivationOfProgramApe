1、反转链表

给定一个链表的头节点head，将其反转，并返回之。

解法1：顺序迭代

在遍历列表过程中，将当前节点的next指向前一个节点，因此需要在改变指针时记录下一个节点的位置。

public ListNode ReverseList(ListNode head)
{
    ListNode pre = null, cur = head, next;
    while(cur != null)
    {
        next = head.next;//记录下一节点
        cur.next = pre;//指向前一节点
        pre = cur;
        cur = next;
    }
    return pre;
}

解法2：递归

使用递归先找到最后一个节点，即反转链表的头节点，并且在递归回升时不会丢失前一节点，之后在回升过程中反转当前节点的指针即可。

public ListNode ReverseList(ListNode head)
{
    if (head == null || head.next == null)//递归退出条件
        return head;
    ListNode newHead = ReverseList(head);//递归至末尾节点
    head.next.next = head;//反转
    head.next = null;//当前节点的指针置空
    return newHead;
}

2、移除链表重复元素

给定一个有序链表的头节点head，移除链表中重复的节点使每个节点仅出现一次，并返回有序的结果。

解法1：顺序迭代

按顺序遍历该有序链表，同时比较是否与后方节点的值相同。若相同则移除后方重复的节点，当前节点继续与下一个节点比较。特别的，仍需要设置一个哨兵来标记返回结果的头节点。

public ListNode DeleteDuplicates(ListNode head)
{
    if (head == null)
        return null;
    ListNode prehead = head;//哨兵节点
    while (head.next != null)
    {
        if (head.val == head.next.val)//移除重复节点
            head.next == head.next.next
        else
            head = head.next;
    }
    return prehead;
}

解法2：递归

这是一个强行的、没必要的递归方法，优点是不需要用哨兵标记返回结果的头节点。

public ListNode DeleteDuplicates(ListNode head)
{
    if (head == null || head.next == null)
        return head;
    else 
        head.next = DeleteDuplicates(head.next);
    if (head.val = head.next.val)
        head.next == head.next.next;
    return head;
}
