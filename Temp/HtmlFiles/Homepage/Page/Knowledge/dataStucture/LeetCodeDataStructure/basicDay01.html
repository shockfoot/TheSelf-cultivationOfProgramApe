1、数组中存在相同元素

给定一个整数数组nums，如果任一值在数组中出现至少两次，返回true，如果数组中每个元素互不相同，返回false。

解法1：双循环暴力求解

两次循环遍历是否有相同的元素。

public bool ContainsDuplicate(int[] nums)
{
    for (int i = 0; i < nums.Length - 1; i++)
    {
        for (int j = i + 1; j < nums.Length; j++)
        {
            if (nums[i] == nums[j])
                return true;
        }
    }
    return false;
}

解法2：排序+一次遍历

将数组排序以后，使用一个循环遍历。

public bool ContainsDuplicate(int[] nums)
{
    Array.Sort(nums);//将数组从小到大排序
    for (int i = 0; i < nums.Length - 1; i++)
    {
        if (nums[i] == nums[i + 1])
            return true;
    }
    return false;
}

2、最大子数组和

给定一个整数数组nums，找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。子数组是数组中的一个连续部分。

解法1：暴力解法

通过双循环遍历全部不同长度的子数组，求和，判断是否是最大和。

public int MaxSubArray(int[] nums)
{
    int maxSum = nums[0], sum;
    for (int i = 0; i < nums.Length; i++)
    {
        sum = nums[i];
        if (sum > maxSum)//判断当前元素是否为最大
            maxSum = sum;
        for (int j = i + 1; j < nums.Length; j++)//遍历当前元素后不同长度的子数组
        {
            sum += nums[j];//求不同长度子数组的和
            if (sum > maxSum)//判断是否为最大和
                maxSum = sum;
        }
    }
    return maxSum;
}

解法2：贪心算法

从左到右累加，如果加和后比当前元素小，那么从当前元素开始继续向右累加。

public int MaxSubArray(int[] nums)
{
    int maxSum = nums[0], tepSum = nums[0];//初始值设为数组第一个元素
    for (int i = 1; i < nums.Length; i++)
    {
        tepSum = Math.Max(nums[i], tepSum + nums[i]);
        maxSum = Math.Max(tepSum, maxSum);//需要及时记录最大和
    }
    return maxSum;
}

贪心算法指的是采用定向的迭代，相继做出贪心选择。每做一次选择，就将问题转化为更小规模的子问题。通过每一步贪心选择，可得到问题的一个最优解。贪心算法在对问题求解时，总是选择当前看来最好的选择，而不从整体上加以考虑，因此算法的结果是局部最优解。

利用贪心算法求解的问题应具备以下的特征：

1、贪心选择性质：该问题的整体最优解可以通过局部最优解的选择到达。

2、无后效性：每次选择可以以来以前做出的选择，但不依赖后面要做出的选择，即已经求解的子问题不受后续阶段的影响。

3、最优子结构性质：该问题的最优解应包含其子问题的最优解。

贪心算法存在的问题：

1、不能保证解是全局最优解，因此不能回溯。

2、一般用来解决求最大或最小解，如购物找零问题，为使找回的零钱硬币数最少，总是从大面值币种开始。

3、贪心算法只能确定某些问题的可行性范围。

解法3：动态规划法

假设nums长度为n，下标从0到n-1。用f(i)代表第i个元素结尾的[连续子数组的最大和]，那么原问题的解便是max{f(i)}。因此，只需要求出f(i)，然后返回f(i)中最大值即可。

对于f(i)的求解可以拆成求f(i-1)和nums[i]的子问题。如果f(i-1)为负数或者0，那么可以舍弃f(i-1)，f(i)的解便是nums[i]，因为：

1、负数加上nums[i]一定比nums[i]更小。

2、0加上nums[i]不会比nums[i]更大。

由此可以得到动态规划转移方程：f(i) = max{f(i - 1) + nums[i], nums[i]}。

public int MaxSubArray(int[] nums)
{
    for (int i = 1; i < nums.Length; i++)
    {
        if (nums[i - 1] > 0)
        {
            nums[i] += nums[i - 1];
        }
    }
    return nums.Max();
}

动态规划指的是将待求解问题分成若干个子问题，先求解子问题，从这若干个子问题中的解得到原问题的解。

适用前提：最优子结构性质、无后效性。

缺点：子问题重叠性。算法过程中会产生各种状态，以空间换时间。

解法4：分治法

希望求解区间M[l, r]上的最大连续子列和maxSum，按照分治算法的思路，将M划分成左子区间L[l, mid]和右子区间R[mid+1, r]，使用递归逐层深入直到区间长度小于1时开始“回升”。

对于任意一个区间M，分成左子区间L和右子区间R：

首先，M中所有元素之和M.totalSum = L.totalSum + R.totalSum。

其次，M中以l为左端点的最大子列只存在两种情况：要么落在L中，即M.lMaxSum = L.lMaxSum；要么横跨L和R，即M.lMaxSum = L.totalSum + R.lMaxSum。

同理，M.rMaxSum = R.rMaxSum或者M.rMaxSum = R.totalSum + L.rMaxSum。

最后，M的最大连续子列存在三种情况：落在L中，即M.maxSum = L.maxSum；落在R中，即M.maxSum = R.maxSum；横跨两个子区间，即M.maxSum = L.rMaxSum + R.lMaxSum。

因此，对于每一个区间，需要维护totalSum，lMaxSum，rMaxSum和maxSum四个变量。

public int MaxSubArray(int[] nums)
{
    return GetInfo(nums, 0, nums.Length - 1).maxSum;
}
//定义一个方法，从数组a中获取区间[l,r]中最大连续子列和
public Status GetInfo(int[] a, int l, int r)
{
    if (l == r)//递归退出条件
    {
        return new Status(a[1], a[1], a[1], a[1]);
    }
    int m = (l + r) >> 1;//右移位运算符
    Status lSub = GetInfo(a, l, m);//左子区间的递归
    Status rSub = GetInfo(a, m + 1, r);//右子区间的递归
    int totalSum = lSub.totalSum + rSub.totalSum;
    int lMaxSum = Math.Max(lSub.lMaxSum, lSub.totalSum + rSub.lMaxSum);
    int rMaxSum = Math.Max(rSub.rMaxSum, rSub.totalSum + lSub.rMaxSum);
    int maxSum = Math.Max(Math.Max(lSub.maxSum, rSub.maxSum), lSub.rMaxSum + rSub.lMaxSum);
    return new Status(lMaxSum, rMaxSum, totalSum, maxSum);//返回从两个子区间得到的大区间
}
//每个子区间需要维护的四个变量
public class Status
{
    public int lMaxSum, rMaxSum, totalSum, maxSum;
    public Status(int lSum, int rSum, int tSum, int mSum)
    {
        lMaxSum = lSum;
        rMaxSum = rSum;
        totalSum = tSum;
        maxSum = mSum;
    }
}

分治法相较于动态规划法来说，时间复杂度相同，但是因为使用了递归，并且维护了四个信息的结构体，运行的时间略长，空间复杂度也不如动态规格法。

但分治法不仅可以解决区间[0,n-1]的问题，还可以解决任意子区间[l,r]的问题。如果把[0,n-1]分治下去出现的所有子区间的信息都用堆式存储的方式记忆化下来，即建成一颗真正的树之后，就可以在O(logn)的时间内求到任意区间内的答案。对于大规模查询的情况下，这种方法的优势便体现了出来。而这棵树就是所谓线段树的数据结构。
