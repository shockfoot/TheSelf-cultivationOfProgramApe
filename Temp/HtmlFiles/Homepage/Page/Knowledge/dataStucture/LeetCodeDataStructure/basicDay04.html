1、重塑矩阵

给定一个由二维数组mat表示的m x n矩阵，以及两个正整数r和c，分别表示想要的重构的矩阵的行数和列数。重构后的矩阵需要将原始矩阵的所有元素以相同的行遍历顺序填充。

如果该操作是可行且合理的，则输出新的重塑矩阵；否则，输出原始矩阵。

解法1：暴力解法

遍历二维数组，将每个元素依次填充至重构的二维数组中。

public int[,] MatrixReshape1(int[,] mat, int r, int c)
{
    if (mat.Length != r * c)//无法重构
        return mat;
    int rindex = 0, cindex = 0;
    int[,] rel = new int[r, c];
    foreach (int item in mat)
    {
        rel[rindex, cindex] = item;
        if (cindex < c - 1)
            cindex++;
        else if (rindex < r - 1)
        {
            rindex++;
            cindex = 0;
        }
    }
    return rel;
}

解法2：二维数组与一维数组的映射

对于一个m行n列的二维数组，可以映射到具有n * m个元素的一维数组，映射关系是：x = r * n + c。相反，一维数组映射到二维数组的映射关系：r = x / n，c = x % n。因此，可以通过该一维数组将两个二维数组元素一一对应。

public int[,] MatrixReshape(int[,] mat, int r, int c)
{
    int m = mat.GetLength(0);
    int n = mat.GetLength(1);
    if (m * n != r * c)
        return mat;
    int[,] rel = new int[r, c];
    for (int x = 0; x < n * m; x++)
    {
        rel[x / c, x % c] = mat[x / n, x % n];
    }
    return rel;
}

2、杨辉三角

给定一个非负整数numRows，生成杨辉三角的前numRows行。

在杨辉三角中，每个数是它左上方和右上方的数的和。

解法1：暴力解法

public IList<IList<int>> Generate(int numRows)
{
    IList<IList<int>> list = new List<IList<int>>();
    for (int i = 0; i < numRows; i++)
    {
        IList<int> row = new List<int>();
        for (int j = 0; j <= i; j++)
        {
            if (j == 0 || j == i)//每行的头尾为1
                row.Add(1);
            else//其它元素为上一行左上和上方元素的和
                row.Add(list[i - 1][j - 1] + list[i - 1][j]);
        }
        list.Add(row);
    }
    return list;
}
