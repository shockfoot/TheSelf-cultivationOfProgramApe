1、标题

在一行文本前输入#来表示标题，#与文本之间需要 ，并且#个数代表标题级数，最多六级。

示例：

# 这是 <h1> 一级标题
## 这是 <h2> 二级标题
### 这是 <h3> 三级标题
#### 这是 <h4> 四级标题
##### 这是 <h5> 五级标题
###### 这是 <h6> 六级标题
####### 最多只支持六级标题

2、强调

用不同的符号包括文本以达到不同的强调作用：*和_的效果是斜体，**和__会加粗文本，~~会为文字增加删除线/中划线，==会高亮显示被包裹文本，~与^分别是上下标。注意：高亮和上、下标需要编辑器支持扩展语法。

示例：

*这会是 斜体 的文字*
_这会是 斜体 的文字_
**这会是 粗体 的文字**
__这会是 粗体 的文字__
_你也可以 **组合** 这些符号_
~~这行文字会被 横线 删除~~
==这行文字会被 高亮 显示==
这个会是~下标~
这个会是^上标^

3、列表

无序列表

要创建无序列表，可以在每个列表项前面添加破折号-、*或+。缩进一个或多个列表项可创建嵌套列表。

示例：

* 可以使用`*`作为标记
+ 也可以使用`+`作为标记
- 也可以使用`-`作为标记
    - 使用缩进可以构成多级无序列表
    - 相同标记符号的会被视为同组

有序列表

要创建有序列表，可以在每个列表项前面添加添加数字并紧跟一个英文句点.。数字不必按数学顺序排列，但是列表应当以数字1起始。

示例：

1. 有序列表以数字和`.`为标记
3. 数字的序列不会影响列表的序列
    3.1 但仍推荐按自然序列编写

在列表中嵌套其他元素

要在保留列表连续性的同时在列表中添加另一种元素，应给该元素置四个空格或一个制表符的缩进。

示例：

* 这是第一个列表项
* 这是第二个列表项
    这是第二个列表项下的一个段落
* 这是第三个列表项

4、引用

使用>创建一个块引用。

块引用可以包含多个段落，为段落之间的空白行添加一个>符号即可。

块引用可以嵌套。在要嵌套的段落前使用两个>符号。

示例：

正如XXX所说:
> 这是一句引用。
    >> 嵌套引用

在列表中嵌套其他元素

块引用可以包含其他Markdown格式的元素，但并非所有元素都可以使用。

5、代码

行内代码

要将单词或短语表示为代码，可以将其包裹在反引号`中。

如果表示为代码的单词或短语中包含一个或多个反引号，则可以通过将单词或短语包裹在双反引号``中。

示例：

`C#`, `Java`, `markdown`

代码块

使用```引入代码块，添加语言名称后可以高亮显示相应关键字

示例：

```C#
private static void Main() {
    int a = 0;
}
```

7、链接

外部链接

链接文本放在中括号内，链接地址放在后面的括号中，链接title可选。语法：[链接显示名](链接地址 "链接title")。

链接title是当鼠标悬停在链接上时会出现的文字，这个title是可选的。

示例：

[正行](https://zhengxingstudio.com "我的个人网站")

自动链接

使用<和>包裹的URL或邮箱会自动转换为链接。

示例：

带格式化的链接

在链接两边使用*、**可以为链接增加文本强调效果。如果要将链接表示为代码，请在方括号中添加反引号`。

示例：

我喜欢支持 **[正行](https://zhengxingstudio.com)**
这里是 *[正行](https://zhengxingstudio.com)*
我正在学习 [`C#`](#C#)

内部链接

格式为[link text](#aim title)，只支持到标题的跳转。

示例：

[1、标题](#1、标题)

8、图片

要添加图像，可以使用感叹号!，然后在方括号增加替代文本，图片链接放在圆括号里，括号里的链接后可以增加一个可选的图片标题文本。URL可以为绝对路径,也可以为相对路径。

示例：

![name](URL)

9、表格

语法

使用|分隔不同单元格，使用-分隔表头。

为了使表格更加清晰，|和-两侧各需要一个空格，最左/右边的|外侧就不需要了。为了美观，可以使用空格对齐不同行的单元格，并在左右两边使用|标记单元格边界。

示例：

| First Header | Second Header |
| ------------ | ------------  |
| Content      | Content       |
| Content      | Content       |

对齐方式

在表头下方的分隔线中加入:，即可标记下方单元格内容的对齐方式。

示例：

| First Header | Second Header | Third Header |
| :----------- | ------------: | :----------: |
| 左对齐       |        右对齐 |   居中对齐   |
| Content      |       Content |   Content    |
