TupleExtensions

描述

  • 定义：public static class TupleExtensions
  • 继承自：Object
  • 命名空间：System
  • 程序集：System.Runtime.dll

TupleExtensions为元组提供扩展方法。尽管这些方法可以直接调用，但它们主要用于C#编译器创建和解构元组。

静态方法

名称描述

Deconstruct<T1, ..., T21>(Tuple<T1, ..., T7, Tuple<T8, ..., T14, Tuple<T15, ..., T21>>>, out T1, ..., out T21)

将元组分解为单独的变量，最多支持21个元素。

ToTuple<T1, ..., T21>(ValueTuple<T1, ..., T7, ValueTuple<T8, ..., T14, ValueTuple<T15, ..., T21>>>)

将值元组转为元组，最多支持21个元素。

ToValueTuple<T1, ..., T21>(Tuple<T1, ..., T7, Tuple<T8, ..., T14, Tuple<T15, ..., T21>>>, out T1, ..., out T21)

将元组转为值元组，最多支持21个元素。
