ValueType

描述

  • 定义：public abstract class ValueType
  • 继承自：Object
  • 命名空间：System
  • 程序集：System.Runtime.dll

ValueType是值类型的基类，但不能自定义直接继承ValueType的类，只能通过struct自定义值类型。基于上述原因，ValueType通常不会直接在代码中使用，但可以在方法中用作参数以限制其为值类型。

ValueType和Object可以通过装/拆箱互相转换，但实际过程中应尽量避免，因为装/拆箱性能开销较大。
