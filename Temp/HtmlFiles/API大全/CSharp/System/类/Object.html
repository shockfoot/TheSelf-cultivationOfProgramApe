Object

描述

  • 定义：public class Object
  • 命名空间：System
  • 程序集：System.Runtime.dll

Object是所有.NET类的最终基类，是类型层次结构的根，其他类默认隐式继承之。

在使用Object时，可以为不同值类型提供重载方法或使用泛型来避免装/拆箱。

构造函数

名称描述

Object()

实例化Object对象。

析构函数

名称描述

Finalize()

~Object()

用于在销毁对象之前对其持有的非托管资源执行清理操作。

如果某个类型重写了Finalize()，GC会在销毁该对象实例之前将其添加到终结队列中并自动调用此方法。终结队列记录托管堆中所有需要执行析构函数的实例。

使用Finalize()释放资源有以下限制：执行时间和顺序不确定；对象会被复活一次。

静态方法

名称描述

Equals(Object, Object)

根据类型判断两对象是否相等。

ReferenceEquals(Object, Object)

通过引用判断两对象是否是同一实例。

在比较值类型时，即使相等也会因装箱返回false。

虚方法

名称描述

GetHashCode()

获取对象的哈希值。

若未重写此方法，引用类型通过Object.GetHashCode()基于引用计算哈希值，值类型通过ValueType.GetHashCode()基于值计算哈希值。相同对象具有相同哈希值，但哈希值相同的对象不一定是同一个。

重写GetHashCode()必须重写Equals()以确保哈希表可以正常工作。

ToString()

将对象转换为字符串形式，默认返回完全限定类型名称。

Equals(Object)

指定对象是否等于当前对象。

值类型重写Equals()可避免反射的使用，引用类型重写可实现值相等性判断。

重写：1、实现IComparable接口的类型必须重写Equals()；2、重写Equals()还必须重写GetHashCode()，否则哈希表可能无法正常工作；3、应考虑实现IEquatable接口以支持强类型测试的相等性，且应返回与Equals()一致的结果；4、重载相等运算符必须重写Equals()方法，且应返回相同的结果。

普通方法

名称描述

GetType()

获取对象的Type对象，进而通过反射获取该类型的所有信息。

MemberwiseClone()

创建浅拷贝副本，即原始对象及其克隆引用的是同一个对象。
