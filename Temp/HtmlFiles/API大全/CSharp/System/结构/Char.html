Char

描述

  • 定义：public readonly struct Char
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

Char，即char，表示UTF-16字符，其值为16位整数。

大多数Unicode字符可由单个Char表示，但编码为基字符、代理项对和/或组合字符序列的字符由多个Char表示。以下情况时，字符由多个Char表示：

  • 象形字符。
  • Unicode Basic Multilingual Plane（BMP）之外的字符。

因为单个字符可以由多个Char表示，所以对单个Char对象进行操作并不总是有意义的。为了避免这种情况，通常可以：

  • 对String进行操作。
  • 使用String.EnumerateRunes。
  • 使用StringInfo类来处理文本元素。
  • 如果字符串包含具有一个或多个组合字符的基字符，则可以调用String.Normalize方法将子字符串转换为单个UTF-16编码的代码单元。

IsControl(Char)

控制字符是格式化字符和其他非打印字符，如ACK、BEL、CR、FF、LF和VT。Unicode标准为控制字符分配从\U0000到\U001F、\U007F、从\U0080到\U009F的代码点。根据Unicode标准，除非应用程序另有规定，否则这些值将被解释为控制字符。有效的控制字符是UnicodeCategory.Control类别的成员。
