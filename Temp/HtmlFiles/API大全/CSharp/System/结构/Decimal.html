Decimal

描述

  • 定义：public readonly struct Decimal
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

Decimal，即decimal，表示十进制浮点数，常用于需要大量有效整数和小数且没有舍入误差的财务计算。Decimal不能消除舍入的需要，但能最大限度地减少由于舍入引起的误差。

Decimal共128位，由1位符号、96位整数以及比例因子组成。比例因子用作96位整数的除数并指定整数的哪一部分为小数，还保留十进制数中的任何尾随零。比例因子隐式地定为数字10的幂，指数范围从0到28，因此，Decimal二进制表示形式为：(-296-296)/100-28，最小为-(296-1)，最大为296-1。
