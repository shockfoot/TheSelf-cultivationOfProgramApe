Double

描述

  • 定义：public readonly struct Double
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

Double，即double，表示双精度64位浮点数，范围包含-1.79769313486232E308~1.79769313486232E308，旨在表示非常大或非常小且通常不精确的值。

Double中0-51位存储有意义的数字或尾数，52-62位存指数，63位存符号。Double精度最高为15位小数，但内部最多能保持17位。

浮点数是不精确的，只能近似于实数，并且这种不精确会随着运算次数的增加而增加，如0.3*10的结果比0.3连续加9个0.3的更准确。浮点数的有效位数决定了浮点数接近实数的精度，这意味着有些运算因为精度不够而无法进行，因此有：

  • 在特定精度下，两相等浮点数可能在比较时因最低有效位数的不同而不相等。
  • 使用二进制浮点数进行数学或比较运算时可能会产生与使用十进制数进行运算不同的结果。
  • 涉及浮点数的值可能不会往返（round-trip，如果一个数可以通过运算变换为另一种形式，且逆操作能将转换后的值转换回原数则称该数可往返）。
  • Double的精度高于Single。

两个Double常因为精度差异或者损失而不相等。在精度损失可能影响比较结果的情况下，调用Math.Round方法以确保两个值具有相同精度或使用允许偏差量比较近似相等性。

与整型的操作不同，整型的运算会在非法操作（如除零或溢出）的情况下引发异常，对浮点数的操作不会引发异常，而是得到零、正无穷大、负无穷大或者非数字的结果。

  • 如果结果对于目标格式来说太小，则结果为零，如当两个非常小的浮点数相乘。
  • 如果结果超过目标格式范围，则结果为PositiveInfinity或NegativeInfinity。
  • 如果运算无效（除数为0、无效运算符、对非数字的运算），则结果为NaN。
