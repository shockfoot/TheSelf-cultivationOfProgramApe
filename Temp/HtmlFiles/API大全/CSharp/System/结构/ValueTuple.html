ValueTuple

描述

  • 定义：public struct ValueTuple<T...>
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

ValueTuple是所有.NET类的最终基类，是类型层次结构的根。通常不需要显式继承Object，因为默认是隐式继承的。

在使用Object时，可以为不同值类型提供重载方法或使用泛型来避免装/拆箱。
