UIntPtr

描述

  • 定义：public readonly struct UIntPtr
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

UIntPtr，即nuint，表示与指针位宽相同的有符号整数，其范围根据系统位宽而变。

构造函数

名称描述

UIntPtr(UInt32)

使用UInt32实例化UIntPtr对象。

UIntPtr(UInt64)

使用UInt64实例化UIntPtr对象。

UIntPtr(Void*)

使用指向内存的指针实例化UIntPtr对象。

字段

名称描述

MaxValue

UIntPtr能表示的最大值。

MinValue

UIntPtr能表示的最小值。

Zero

只读，UIntPtr类型的0。

Size

UIntPtr所占内存大小，单位字节。
