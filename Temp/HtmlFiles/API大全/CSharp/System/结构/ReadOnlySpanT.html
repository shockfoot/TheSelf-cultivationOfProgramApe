ReadOnlySpan<T>

描述

  • 定义：public readonly ref struct ReadOnlySpan<T>
  • 继承自：ValueType
  • 命名空间：System
  • 程序集：System.Runtime.dll

ReadOnlySpan<T>表示任意连续内存区域且是类型和内存安全的，是在栈分配的引用结构体，因此不支持装箱、无法在Lambda表达式中获取、不能分配给动态变量并且不能实现任何接口。

ReadOnlySpan<T>常用于引用数组的元素或数组的一部分。然而，与数组不同的是，ReadOnlySpan<T>实例可以指向托管内存、本机内存或堆栈上管理的内存。

ReadOnlySpan<T>有一个枚举器ReadOnlySpan<T>.Enumerator，可以使用foreach遍历。ReadOnlySpan<T>.Enumerator包含Current和MoveNext()，但不包含Reset()。ReadOnlySpan<T>.Enumerator是一个引用结构体，所以ReadOnlySpan<T>不需要实现IEnumerator或IEnumerator接口。
