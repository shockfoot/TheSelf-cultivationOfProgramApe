`public readonly struct Char`

`Char`表示UTF-16字符，其值为16位整数。

大多数Unicode字符可以由单个`Char`表示，但编码为基字符、代理对和/或组合字符序列的字符由多个`Char`表示，因此因此，`String`中的`Char`结构不一定等同于单个Unicode字符。以下情况时，字符由多个`Char`表示：

- 象形字符；
- Unicode Basic Multilingual Plane（BMP）之外的字符。

`Char`可以通过指定字符、Unicode转义序列（即`\u`+四位十六进制字符，不可省略前导零）、十六进制转义序列（即`\x`+四位十六进制字符，可省略前导零）、字符编码赋值。

### IsControl

是否为Unicode控制字符。

控制字符是格式化字符和其他非打印字符，如ACK、BEL、CR、FF、LF和VT。Unicode标准为控制字符分配从`\U0000`到`\U001F`、`\U007F`、从`\U0080`到`\U009F`的代码点。根据Unicode标准，除非应用程序另有规定，否则这些值将被解释为控制字符。有效的控制字符是`UnicodeCategory.Control`类别的成员。

- `public static bool IsControl(Char)`
- `public static bool IsControl(String, Int32)`

### IsHighSurrogate

是否为高代理项。UTF-16编码允许使用两个16位代码来表示抽象字符，这被称为代理对。这对中的第一个元素是高代理，其码点的范围可以从U+D800到U+DBFF。单独的代理项无意义。

- `public static bool IsHighSurrogate(String, Int32)`

### IsLowSurrogate

是否为低代理项。UTF-16编码允许使用两个16位代码来表示抽象字符，这被称为代理对。这对中的第二个元素是低代理，其码点的范围可以从U+DC00到U+DFFF。单独的代理项无意义。
