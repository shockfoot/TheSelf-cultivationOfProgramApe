单例模式即所谓一个类只能有一个实例，即类只能在内部实例化一次，然后提供这一实例，外部无法对此类实例化。

特点：只能自己创建自己的全局唯一的实例。

构建单例通常需要在类内部声明一个同类型的静态私有字段，提供公开静态属性以访问该字段。为了禁止外部实例化该类，将构造函数私有化。

``` C#
public class Manager
{
    private static Manager instance;
    public static Manager Instance { get; private set; }
    private static Manager()
    {
        instance = new Manager();
    }
    private Manager() { }
}
```
