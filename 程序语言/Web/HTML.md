# 超文本标记语言

**超文本标记语言**（HyperText Markup Language，HTML）是一种描述网页的标记语言，由一套标记标签定义。**标签**是一种由尖括号`<>`包裹的关键字，通常成对出现。标签对中的第一个为**开始标签**，第二个为**结束标签**，开始和结束标签也被称为**开放标签**和**闭合标签**。闭合标签是可选的，但不适用闭合标签会产生不可预料的后果。**元素**和标签的含义相似，但元素包括开始标签、结束标签以及其所包裹的内容。**单标签**没有结束标签，使用`/`闭合。标签对大小写不敏感，但W3C在HTML 4中推荐使用小写，且在XHTML中强制小写。

使用HTML编写的网页文件以.html或.htm为后缀。

## DOCTYPE声明

`<!DOCTYPE html>`声明位于HTML文档最前面，有助于浏览器正确显示网页，避免怪异模式，。DOCTYPE声明不区分大小写。

## 注释

HTML注释为`<!-- -->`，可以提高其可读性。浏览器会忽略注释，也不会显示注释。

## HTML骨架

| 标签       | 作用                                                         |
| :--------- | :----------------------------------------------------------- |
| `<html>`   | 定义HTML文档，限定文档的开始和结束。所有标签都必须被html标签包裹。 |
| `<head>`   | 定义HTML文档的头部。头部描述了文档的属性和信息，如标题、与其他文档的关系等。绝大多数头部信息不会作为内容显示给用户。 |
| `<body>`   | 定义HTML文档的主体，包含文档的所有显示内容，如文本、图片、超链接、表格等，是用户可以直观看到的内容。 |
| `<title>`  | 定义HTML文档的标题，显示在浏览器窗口的标题栏或状态栏上。title标签是head标签中唯一要求包含的东西，有利于搜索引擎优化（SEO）。 |
| `<meta />` | 提供HTML文档的元数据，如charset属性指定编码格式，`name="keywords"`指定关键词，`name="description"`指定描述，`name="author"`指定作者等。 |
| `<base />` | 描述HTML文档全局的链接地址或链接打开方式，属性hret指定默认链接，target指定链接打开方式。 |
| `<link />` | 定义与外部资源之间的关系，属性rel指定关系，type指定类型，href指定地址。 |
| `<style>`  | 定义HTML文档的渲染样式。                                     |
| `<script>` | 定义脚本。                                                   |

## HTML常用标签

### 基础标签

| `<hr />` |定义水平线。|
| `<img />` |定义图像，属性src指定图片路径，alt指定图像代替文本，title指定鼠标悬停时提示文本，with指定宽度，height指定高度。|
| `<a>` |定义超链接，可以包裹文字、图片等内容，属性href指定跳转目标地址。当跳转地址为`#`加当前页面中位置标记（任意元素的id，a标签的name等）可实现锚点链接。target指定链接如何在浏览器中打开：`_blank`新窗口，`_self`当前窗口。title指定鼠标悬停时提示文本，download指定下载文件而不跳转。<br />超链接具有未点击、悬浮、点击时、访问过等状态。鼠标悬浮在超链接上时会改变指针样式。|
| `<header>` |定义头部区域。|
| `<nav>` |定义导航区域。|
| `<article>` |定义完整的内容块，如一篇博客、用户评论等。|
| `<section>` |定义文章中的节，如章节、页眉、页脚等。|
| `<silder>` |定义侧边栏区域。|

### 表单标签

表单在Web网页中可以让用户填写信息，从而采用用户信息，实现交互。表单由容器和控件组成，控件包括输入框、按钮等。一个完整的表单包括表单标签、表单域、表单按钮。

| 标签         | 作用                                                         |
| :----------- | :----------------------------------------------------------- |
| `<form>`     | 定义表单，属性action指定服务器地址，name指定表单名称，method指定数据提交方式，分为get（URL栏显示，用于提交少量数据）和post（URL栏不显示，用于提交大量数据）。 |
| `<fieldset>` | 将表单内元素分组，并在相关元素周围绘制边框。                 |
| `<legend>`   | 为fieldset元素定义标题。                                     |
| `<input />`  | 定义表输入元素，属性type指定类型，text文本框，password密码框，radio单选框（name属性分组），checkbox复选框（name属性分组），submit提交按钮。 |
| `<textarea>` | 定义多行文本输入框，属性cols指定列数，rows指定行数。         |
| `<label>`    | 为input元素定义标注，属性for指定绑定的input控件ID。用户点击label时绑定的input控件会自动获得焦点。 |
| `<select>`   | 定义下拉选框。                                               |
| `<optgroup>` | 将相关选项分组。                                             |
| `<option>`   | 定义选项，属性value指定值，selected指定默认选项。            |

## 路径

通过路径可以指定资源，如图像、音频、其他文件等。路径分绝对路径、相对路径和网络路径。

绝对路径是电脑的盘符与访问的具体地址。相对路径是两者路径的相对关系，同级路径下可以直接访问，非同级路径下用`/`表示子级关系，`../`表示父级关系，`./`表示同级关系。网络路径则为网络服务器中的资源地址。

## 属性

HTML元素可以设置属性。属性可以为元素添加附加信息。属性一般位于开始标签，总以键值对形式出现，属性值总是被包括在引号内（通常使用双引号，但当属性值本身就含有双引号时可以使用单引号）。

通过class属性可以为元素指定类，多个类以` `分隔。使用id属性可以指定ID，每个元素只能有唯一一个ID。

## 元素类型

HTML 5之前，元素可分为按**块元素**、**内联元素**。在HTML 5中，元素按照内容模型区分，可分为元数据型（metadata content）、区块型（sectioning content）、标题型（heading content）、文档流型（flow content）、语句型（phrasing content）、内嵌型（embedded content）、交互型（interactive content）。元素不属于任何一个类别则被成为**穿透**的。元素可能属于不止一个类别则被成为**混合**的。

| 块元素                           | 内联元素                       |
| :------------------------------- | :----------------------------- |
| 在页面中独占一行，自上而下排列。 | 在页面中仅占自身内容大小尺寸。 |
| 可以设置宽高属性。               | 不能设置宽高属性。             |
| 可嵌套行内元素与块元素。         | 只能嵌套内联元素。             |

- 块元素：div、p、h1-h6、hr、ol、ul、li、table、form等。
- 内联元素：span、a、b、strong、i、em、ins、del等。
- 行内块元素（不换行，能设置宽高）：img、input、button等。
