# Markdown编程指南

## 简介

Markdown是一种**轻量级标记语言**，可以通过纯文本格式来编写结构化文档。Markdown文件后缀为`.md`或`.markdown`，可以导出HTML、PDF等多种格式的文档。

> Markdown由John Gruber于2004年创建。

相比于传统的标记语言如HTML，Markdown语法简单，学习成本低，编写效率高，专注于内容而非格式细节。

## 语法

### 标题

Markdown标题有两种格式：

- 使用三个`=`或`-`标记一级标题和二级标题。
- 使用1至6个`#`标记一级标题至六级标题，`#`与内容之间用` `分隔。

```markdown
我是一级标题
===

我是二级标题
---

# 我是一级标题

## 我是二级标题

### 我是三级标题

#### 我是四级标题

##### 我是五级标题

###### 我是六级标题
```

在一个文档中，通常只使用一个一级标题作为文档的主标题。标题的层次结构应该遵循逻辑顺序，不应该跳级使用。

大多数Markdown编译器会自动为标题创建锚点（Anchor），便于页面内跳转。

### 文本格式

段落没有特殊格式。段落的换行是使用两个以上` `加上回车，也可以在段落后使用一个空行表示重新开始一个段落。

```markdown
这是一个段落  
这是另一行

这是一个段落

这是另一个段落
```

粗体使用两个`*`或`_`包围内容，斜体使用一个`*`或`_`包围内容，粗斜体则使用三个`*`或`_`包围内容。

```markdown
这是**粗体**。
这是__粗体__。
这是*斜体*。
这是_斜体_。
这是***粗斜体***。
这是___粗斜体___。
```

上标使用一个`^`包围内容，下标使用一个`~`。上、下标不是标准Markdown语法，但许多扩展支持。

```markdown
这是^上标^。
这是~下标~。
```

分隔线可以在一行中使用三个以上的`*`、`-`或`_`表示，可以在符号中间插入` `。

```markdown
***

---

___

* * *
```

删除线使用两个`~`包围内容。

```markdown
这是~~删除线~~。
```

文本高亮使用两个`=`包围内容。文本高亮不是标准Markdown语法，但许多扩展支持。

```markdown
这是==高亮文本==。
```

### 列表

Markdown支持有序列表和无序列表。

无序列表使用`*`、`-`或`+`作为标记，与内容之间用` `隔开（建议使用`-`）。

```markdown
* 第一项
* 第二项
* 第三项

- 第一项
- 第二项
- 第三项

+ 第一项
+ 第二项
+ 第三项
```

有序列表使用数字加`.`作为标记，与内容之间用` `隔开。

```markdown
1. 第一项
2. 第二项
3. 第三项
```

列表可以嵌套以创建多层次结构。列表嵌套只需要在子列表前添加两个或四个` `统一缩进即可。

任务列表是GitHub风格Markdown的扩展功能，现在被广泛支持。

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个未完成的任务
```

如果列表项中包含多段内容，可以使用换行和缩进来显示。

```markdown
1. 第一项
    第一行
    第二行
2. 第二项
    > 引用
3. 第三项
    需要换行显示
4. 第四项
```

### 引用

使用`>`标记引用，与内容之间用` `分隔。空行引用仅使用`>`即可。当引用多行时，可以仅在第一行使用标记以简化写法。

引用可以嵌套。引用块内可以几乎保护其他所有Markdown元素。

```markdown
> 引用
>
> 多行
```

> 引用
>
> 多行
包含的多行内容
只需要在第一行使用标记
> 第一层
> > 第二层

### 代码

行内代码使用两个`` ` ``包围内容。当需要在行内代码中显示`` ` ``或其他特殊字符时，使用多个`` ` ``包围内容，并使用` `与内容隔开。

```markdown
这是`行内代码`。
这是`` `行内代码` ``。
```

代码块可以使用四个` `或者一个制表符来简单标记。

```markdown
这是段落。

    这是缩进式代码块。
    这是缩进式代码块。
    这是缩进式代码块。

这是段落。
```

代码块也可以使用三个`` ` ``包围内容，并可以指定一种语言。

常用语言标识符列表：

- javascript/js：JavaScript
- python/py：Python
- html：HTML
- css：CSS
- sql：SQL
- json：JSON
- xml：XML
- bash/shell：Shell脚本
- java：Java
- cpp/c++：C++
- csharp/c#：C#
- php：PHP
- ruby/rb：Ruby
- go：Go语言
- rust：Rust
- typescript/ts：TypeScript

某些渲染器支持通过特定的语法或配置显示行号。

```js {.line-numbers}
function test() {

}
```

可以使用`diff`，然后在代码行前添加`+`或`-`表示版本控制中代码的添加、删除或修改。

```diff
function test() {
-    let index = 0;
+    let index = 1;
}
```

### 链接

链接的使用方法有`[链接名称](链接地址)`、`[链接名称](链接地址 "可选的标题")`、`<链接地址>`。链接地址可以是网址、邮箱、电话等。

参考链接将链接定义和使用分离，适合多次引用相同链接的情况。当链接文字与参考标签相同时，可以省略第二个方括号中的文本。

```markdown
[链接文字][参考标签]

[链接文字][]

[参考标签]: 链接地址 "可选标题"
```

锚点链接用于在同一文档内跳转，适合长文档。

标题会自动生成锚点。生成的锚点名称通常是标题的小写形式，空格替换为连字符并移除特殊字符。顶部返回链接的地址为`#`。

可以使用`<a>`标签手动创建锚点。

```markdown
## 目录
- [第一章：介绍](#第一章)
- [第二章：安装](#第二章)

# 第一章
这里是第一章内容

# 第二章
这里是第二章内容

<!-- 自定义锚点 --> 

<a id="custom-anchor"></a>
## 自定义锚点位置

[跳转到自定义位置](#custom-anchor)

<!-- 回到顶部链接 --> 

[回到顶部](#)
```

### 脚注

类似于参考链接，可以使用脚注对文本进行补充说明。

```markdown
[^要注明的文本]

[^要注明的文本]: 说明。
```

### 图片

图片的语法为`![替代文字](图片路径 "图片标题")`。替代文字是在图片无法显示时提供替代信息，同时对无障碍访问和SEO很重要。可以向参考链接一样对图片路径使用变量。

```markdown
[替代文字][1]

[1]: 图片路径 "图片标题"
```

图片可以和链接组合使用。

```markdown
[![图片替代文字](图片URL)](链接URL)
```

### 表格

Markdown使用`|`分隔不同单元格，使用`-`分隔表头和其他行。

```markdown
| 表头 | 表头 |
| ---- | ---- |
| 单元格 | 单元格 |
| 单元格 | 单元格 |
```

可以使用`---:`、`:---`和`:---:`设置内容和标题的对齐方式，默认为居中对齐。

表格单元格内可以使用大部分Markdown语法。单元格内容较长时可以使用`<br />`标签换行或使用简单说明与链接。

| 表头 | 表头 |
| ---- | ---- |
| 单元格 | 单元格 |
| 单元格 | 单元格 |
