`public abstract class Enum`

`Enum`是一组命名常量，是.NET Framework中所有枚举的基类，其基础类型是任何整型。如果未显式声明基础类型，则为`Int32`。绝不应创建基础类型为非整型或`Char`的枚举类型。虽然可以通过使用反射创建这样的枚举类型，但使用结果类型的方法调用是不可靠的，也可能引发其他异常。

在定义枚举类型时通常：

- 如果尚未定义值为0的枚举成员，请考虑创建`None`枚举常量；
- 如果应用程序必须表示明显的默认情况，请考虑使用值为零的枚举常量来表示它；
- 不要指定供将来使用的枚举常量；
- 当定义将枚举常量作为值的方法或属性时，请考虑验证该值。

枚举的一个常见用法是表示一组互斥值。一个枚举实例反映多个枚举常量是没有意义的。然而，在其他情况下，枚举对象的值可以包括多个枚举成员，每个成员表示枚举值中的一个位字段。`Flags`属性可用于指示枚举由位字段组成。在定义按位枚举并应用`Flags`时，应：

- 仅当要对数值执行逐位运算（AND、OR、EXCLUSIVE OR）时，才对枚举使用`Flags`；
- 以2的幂定义枚举常数，意味着组合枚举常数中的各个标志不重叠；
- 考虑为常用的标志组合创建枚举常量；
- 如果将负数定义为标志枚举常量，由于许多标志位置可能设置为1，将会使代码混乱并导致编码错误；
- 测试标志是否设置为数值的一种方便方法是调用实例`HasFlag`方法，相当于在数值和标志枚举常量之间执行逐位AND运算，将数值中与标志不对应的所有位设置为零，然后测试该运算的结果是否等于标志枚举常量；
- 使用`None`作为值为零的标志枚举常量的名称；
- 不要仅定义枚举值来镜像枚举本身的状态。

由于枚举类型是由语言结构定义的，因此除了从`Enum`继承的方法之外，不能为枚举类型定义自定义方法，但是可以使用扩展方法向特定枚举类型添加功能。

## 静态方法

### Format

根据指定格式将指定枚举类型转换为其等效字符串表示形式。

- `public static string Format(Type, Object, String)`

### GetName

获取指定枚举中具有指定值的常量的名称。

- `public static string? GetName(Type, Object)`
- `public static string? GetName<TEnum>(TEnum) where TEnum : struct`

如果多个枚举成员具有相同的基础值，则此方法保证返回其中一个枚举成员的名称，但并不保证将始终返回同一枚举成员的名称。

### GetNames

获取指定枚举中所有常量的名称并以数组形式返回。返回值数组的元素按枚举常量的二进制值排序（即按其无符号大小）。如果存在具有相同值的枚举常量，则未指定其对应名称的顺序。

- `public static string[] GetNames(Type)`
- `public static string[] GetNames<TEnum>() where TEnum : struct`

### GetValues

获取指定枚举中常量值的数组。数组元素按枚举常量的二进制值排序（即按其无符号大小）。此方法返回一个数组，该数组包含enumType枚举的每个成员的值。如果多个成员具有相同的值，则返回的数组包含重复的值。

在仅反射上下文中使用反射无法调用`GetValues`方法。相反，可以通过使用`Type.GetFields`方法获取表示枚举成员的FieldInfo对象数组，然后在数组的每个元素上调用`FieldInfo.GetRawConstantValue`方法来检索所有枚举成员的值。

- `public static Array GetValues(Type)`
- `public static TEnum[] GetValues<TEnum>() where TEnum : struct`

### GetUnderlyingType

返回指定枚举的基础类型。`Enum`结构允许将值表示为命名常量，但其数据类型为其基础类型。

- `public static Type GetUnderlyingType(Type)`

### ToObject

- `public static object ToObject(Type, Byte)`
- `public static object ToObject(Type, Int16)`
- `public static object ToObject(Type, UInt16)`

- `public static object ToObject(Type, UInt32)`
