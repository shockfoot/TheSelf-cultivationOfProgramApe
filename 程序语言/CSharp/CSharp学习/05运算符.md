C#中运算符分为：算术运算符（对数值操作数执行算术运算）、比较运算符（比较数值操作数）、布尔逻辑运算符（对`bool`操作数执行逻辑运算）、位运算符和移位运算符（对整数类型的操作数执行位运算或移位运算）。运算符可通过重载，为用户定义类型的操作数指定运算行为。

## 算术运算符

算术运算符包括一元增量`++`、减量`--`、加`+`和减`-`以及二元加法`+`、减法`-`、乘法`*`、除法`/`和取余`%`。算术运算符可用于所有整型和浮点型。

- 增量`++`和减量`--`：将操作数按1递增和递减。操作数必须是已赋值变量、属性访问器或索引器访问器。二者都支持**前/后缀**运算。前缀运算是先增/减再返回结果；后缀则先返回值，再增/减。

``` C#
int i = 3;
Console.WriteLine(i); // i = 3
Console.WriteLine(--i); // i = 2
Console.WriteLine(i++); // i = 2
Console.WriteLine(i); // i = 3
```

- 一元加`+`和减`-`：一元`+`返回操作数的值，一元`-`返回操作数的相反数。`unlong`类型不支持一元`-`。

``` C#
Console.WriteLine(+4); // output: 4
Console.WriteLine(-4); // output: -4
Console.WriteLine(+(-4)); // output: -4
Console.WriteLine(-(-4)); // output: 4
```

- 加法`+`：计算左右操作数的和。`+`还可用于字符串串联和委托组合。

- 减法`-`：从左操作数中减去右操作数。`-`还可用于删除委托。

- 乘法`*`：计算左右操作数的乘积。一元`*`运算符是*指针间接运算符*。

- 除法`/`：用左操作数除以右操作数。对于两个整型操作数，结果为整型，且向下取整；若要获得浮点型结果，需要显示转换。当操作数至少有一个为浮点型，结果为浮点型，其值等于两个操作数之商。当一个操作数为`decimal`时，另一个需要显示转换。

- 取余`%`：计算左操作数除以右操作数后的余数。对于两个整型操作数，`a%b`的结果为`a-(a/b)*b`的值。非零余数的符号与左操作数的符号相同。对于`float`和`double`操作数，有限的`x`和`y`的`x%y`的结果是值`z`，其中`z`（如果不为零）的符号与`x`相同；`z`的绝对值是`|x|-n*|y|`，其中`n`是小于或等于`|x|/|y|`的最大可能整数。对于`decimal`操作数，`%`等效于`System.Decimal`类型的余数运算符。

``` C#
Console.WriteLine(5 % -4); // output: 1
Console.WriteLine(-5 % 4); // output: -1
Console.WriteLine(-5.2f % 2.0f); // output: -1.2
Console.WriteLine(5.9m % 3.1m); // output: 2.8
```

按优先级由高到低对算术运算符排序：后缀增量`++`和减量`--` > 前缀增量`++`和减量`--`以及一元`+`和`-` > 乘法`*`、除法`/`和取余`%` > 加法`+`和减法`-`。二元算数运算符是**左结合运算符**，即具有相同优先级的运算符按从左至右的顺序计算。可使用括号`()`更改由运算符优先级和计算顺序。

用户定义类型可以重载一元（`++`、`--`、`+`和`-`）和二元（`*`、`/`、`%`、`+`和`-`）算术运算符。

## 赋值运算符

赋值运算符`=`将其右操作数的值赋给变量、属性或由其左操作数给出的索引器元素，为**右联运算符**。赋值表达式的结果是分配给左操作数的值。右操作数类型必须与左操作数类型相同，或可隐式转换为左操作数的类型。

``` C#
a = b = c;
// 计算结果为
a = (b = c);
```

复合运算符`op=`（等效于`x = x op y`）：二元算术运算符、逻辑`&`、`|`和`^`运算符以及位运算符`&`、`|`、`^`、`<<`和`>>`支持复合赋值表达式。由于*数值提升*，`op`运算的结果可能不会隐式转换为`x`的`T`类型。此时，如果`op`是预定义的运算符且运算结果可以显式转换为`x`的类型`T`，则`x op= y`的复合赋值表达式等效于`x = (T)(x op y)`，但`x`仅计算一次。`+=`和`-=`分别还可用于订阅和取消订阅事件。

``` C#
// 算术运算符的复合赋值表达式
byte a = 100;
byte b = 200;
var c = a + b;
Console.WriteLine("{0}-{1}", c.GetType(), c); // output: System.Int32-300
a += b;
Console.WriteLine(a); // output: 44

// 逻辑运算符的复合赋值表达式
bool test = false;
test &= false; // test = false;
test |= true; // test = true;
test ^= false; // test = true;

uint a = 0b_1111_1000;
a &= 0b_1001_1101; // a = 0b_1001_1000
a |= 0b_0011_0001; // a = 0b_1011_1001
a ^= 0b_1000_0000; // a = 0b_0011_1001
a <<= 2; // a = 0b_1110_0100
a >>= 4; // a = 0b_0000_1110
```

用户定义类型**不能**重载赋值运算符，但可以定义到其他类型的隐式转换，从而可以将用户定义类型的值分配给其他类型的变量、属性或索引器元素。用户定义类型**不能显式重载**复合赋值运算符。但若用户定义类型重载了二元运算符`op`，则`op=`运算符（如果存在）也将被隐式重载。

## 比较运算符

比较运算符包括大于`>`、 小于`<`、等于`==`、大于等于`>=`、小于等于`<=`和不等于`!=`，用于比较操作数，返回`true`和`false`。所有整型和浮点型都支持比较运算符。当操作数为`char`时，将比较对应的字符代码。当操作数为`enum`时，会比较相应的基础类型值。

- 大于`>`和小于`<`：如果左操作数大于（小于）右操作数，返回`true`，否则返回`false`。

- 等于`==`和不等于`!=`：如果操作数（不）相等，返回`true`，否则返回`false`。

- 大于`>=`和小于`<=`：如果左操作数大于（小于）等于右操作数，返回`true`，否则返回`false`。

`==`和`!=`不仅可以比较值类型，也可以比较其他类型。对于非记录引用类型，比较是否引用同一对象。对于记录类型，当两个记录操作数均为`null`或所有字段的对应值和自动实现的属性相等时，两个记录操作数都相等。对于`string`，如果均为`null`或者二者长度相等且在每个字符位置有相同字符，则两操作数相等。对于`delegate`，若两个运行时间类型相同的委托操作数均为`null`，或其调用列表长度系统且在每个位置具有相同的条目，则二者相等。

用户定义类型可以重载`<`、`>`、`==`、`!=`、`<=`和`>=`运算符。如果某类型重载`<`或`>`、`<=`或`>=`、`==`或`!=`运算符之一，它必须同时重载另一个。记录类型不能显式重载`==`和`!=`运算符。

## true/false运算符

`true`运算符返回`bool`值`true`，以指明其操作数一定为true。`false`运算符返回`bool`值`true`，以指明其操作数一定为false。无法确保`true`和`false`运算符互补，即`true`和`false`运算符可能同时针对同一个操作数返回`bool`值`false`。如果某类型定义这两个运算符之一，它还必须定义另一个运算符。

## 布尔逻辑运算符

布尔逻辑运算符对`bool`操作数执行逻辑运算，并返回`bool`结果。布尔逻辑运算符包括一元逻辑非`!`，二元逻辑与`&`、逻辑或`|`和逻辑异或`^`（**始终计算两个操作数**），二元条件逻辑与`&&`和条件逻辑或`||`（**仅在必要时计算右操作数**，亦称短路逻辑运算符）。对于整型，`&`、`|`、`^`执行位逻辑运算。

- 逻辑非`!`：计算操作数的逻辑非。若操作数的结果为`false`，返回`true`；否则返回`false`。

- 逻辑与`&`：计算操作数的逻辑与。若两操作数结果都为`true`，则返回`true`；否则，返回`false`。即使左操作数结果为`false`，`&`也会计算右操作数，无论右操作数的值为何，运算结果都为`false`。

- 逻辑或`|`：计算操作数的逻辑或。若两操作数结果至少有一个为`true`，则返回`true`；否则，返回`false`。即使左操作数结果为`true`，`|`也会计算右操作数，无论右操作数的值为何，运算结果都为`true`。

- 逻辑异或`^`：计算操作数的逻辑异或。如果两操作数结果都为`true`或`false`，则返回`true`；否则返回`false`。

- 条件逻辑与`&&`：若两操作数结果都为`true`，则返回`true`；否则，返回`false`。如果左操作数结果为`false`，则不计算右操作数。

- 条件逻辑与`||`：若两操作数结果至少有一个为`true`，则返回`true`；否则，返回`false`。如果左操作数结果为`true`，则不计算右操作数。

对于`null?`，逻辑与`&`、逻辑或`|`支持三值逻辑。

`&`：仅当其两个操作数的计算结果都为`true`时，`&`才返回`true`。如果`x`或`y`的计算结果为`false`，则`x&y`将返回`false`（即使另一个操作数的计算结果为`null`）。否则，`x & y`的结果为`null`。

`|`：仅当其两个操作数的计算结果都为`false`时，`|`才返回`false`。如果`x`或`y`的计算结果为`true`，则`x|y`将返回`true`（即使另一个操作数的计算结果为`null`）。否则，`x | y`的结果为`null`。

按优先级从高到低对逻辑运算符进行排序：`!` > `&` > `^` > `|` > `&&` > `||`。使用括号`()`可以更改运算符优先级和计算顺序。

用户定义类型可以重载`!`、`&`、`|`和`^`运算符，无法重载条件逻辑运算符`&&`和`||`。不过，如果用户定义类型以某种方式重载`true`和`false`运算符以及`&`或`|`运算符，可以对相应类型的操作数执行`&&`或`||`运算。

## 条件运算符

条件运算符`?:`也称为三元条件运算符，用于计算布尔表达式，并根据布尔表达式的计算结果`true`还是`false`来返回两个表达式中的一个结果，为**右联运算符**。

``` C#
// 语法：condition ? consequent : alternative

Console.WriteLine( temperatrue > 26 ? "hot" : "cold");

a ? b : c ? d : e;
// 等价于
a ? b : (c ? d : e);
```

从C# 9.0开始，条件表达式由目标确定类型。也就是说，如果条件表达式的目标类型是已知的，则`consequent`和`alternative`的类型必须可隐式转换为目标类型。如果条件表达式的目标类型是未知的（例如使用`var`关键字时）或者采用C# 8.0及更早版本，则`consequent`和`alternative`的类型必须相同，或者必须存在从一种类型到另一种类型的隐式转换。

用户定义类型不能重载条件运算符。

## 位运算符

位运算符包括一元按位求补`~`，二进制左移`<<`、右移`>>`、无符号右移`>>>`，二进制逻辑与`&`、逻辑或`|`和逻辑异或`^`，可用于整型和`char`类型的操作数执行位运算或移位运算。这些运算符是针对`int`、`uint`、`long`和`ulong`定义的。如果两个操作数都是其他整数类型（`sbyte`、`byte`、`short`、`ushort`或`char`），它们的值将转换为`int`，并返回`int`结果。如果操作数是不同的整型，它们的值将转换为最接近的整型。

位运算和移位运算永远不会导致溢出，并且不会在已检查和未检查的上下文中产生相同的结果。

- 按位求补`~`：反转每个位产生其操作数的按位求补。也可以使用`~`来声明终结器。

- 左移位`<<`：将其左操作数向左移动右操作数定义的位数，结果为左操作数乘2的右操作数次方。左移运算会放弃超出结果类型范围的高阶位，并将低阶空位设置为零。

- 右移位`>>`：将其左操作数向右移动右操作数定义的位数，结果为左操作数除2的右操作数次方。右移位运算会放弃低阶位。如果左操作数的类型是`int`或`long`，则执行**算术移位**：左操作数的最高有效位（符号位）的值将传播到高顺序空位。也就是说，如果左侧操作数为非负，高顺序空位设置为0，如果为负，则将该位置设置为1。如果左操作数类型是`uint`或`ulong`，则执行**逻辑移位**：高顺序空位始终设置为零。

- 无符号右移位`>>>`：所有整数类型执行**逻辑移位**，无论左侧参数的类型如何，高阶位始终设置为零。

- 位逻辑与`&`：计算其整型操作数的位逻辑AND，即按二进制位依次进行与运算。

- 位逻辑或`|`：计算其整型操作数的位逻辑OR，即按二进制位依次进行或运算。

- 位逻辑异或`^`：计算其整型操作数的位逻辑XOR，即按二进制位依次进行异或运算。

``` C#
uint a = 0b_00001111_00001111_00001111_00001100;
uint b = ~a; // b = 0b_11110000_11110000_11110000_11110011
uint c = a << 2; // c = 0b_00111100_00111100_00111100_00110000
uint d = a >> 2; // d = 0b_00000011_11000011_11000011_11000011

uint x = 0b_1111_1000;
uint y = 0b_1001_1101;
uint m = x & y; // m = 0b_1001_1000
uint n = x | y; // n = 0b_1111_1101
uint o = x ^ y; // o = 0b_0110_0101
```

按优先级从高到低对位运算符和移位运算符排序：按位求补`~` > 移位`<<`和`>>` > 位逻辑与`&` > 位逻辑异或`^` > 位逻辑或`|`。可使用括号`()`更改运算符优先级和计算顺序。

在C#11之前，对于移位运算符`<<`和`>>`，右操作数的类型必须为`int`，或具有预定义隐式数值转换为`int`的类型。C#11中去除了这一限制。对于`x << count`和`x >> count`表达式，实际移位计数取决于`x`的类型：若`x`为`int`或`uint`，则移位计数由右操作数的低阶五位定义，即`count & 0x1F`（或`count & 0b_1_1111`）计算得出；若为`long`或`ulong`，则移位计数由右操作数的低阶六位定义，即`count & 0x3F`（或`count & 0b_11_1111`）得出。因此，即使右操作符的值大于左操作符中的位数，移位运算的结果也不可为零。

所有`enum`类型也支持`~`、`&`、`|`和`^`运算符。对于相同`enum`类型的操作数，对底层整数类型的相应值执行逻辑运算。通常需要使用位逻辑运算符的`enum`类型，需使用`Flags`特性定义。

用户定义的类型可以重载`~`、`<<`、`>>`、`&`、`|`和`^`运算符。如果用户定义类型`T`重载`<<`或`>>`运算符，则左操作数的类型必须为`T`且右操作数的类型必须为`int`。

## 成员访问运算符

可以使用`.`来访问命名空间内的嵌套命名空间或者类型的成员，使用`[]`访问数组、索引器或指针元素。

``` C#
using System.Collections.Generic;
System.Collections.Generic.IEnumerbale<int> numbers = new int[] { 1, 2, 3 };
Console.WriteLine(".可以访问类型成员");

// 在声明数组类型或实例化数组实例时，也会使用方括号
int[] nums = new int[4];
nums[0] = nums[1] = 2;
// 索引器访问
Dictionary<string, int> dic = new Dictionary<string, int>();
dic["one"] = 1;
Console.WriteLine(dic["one"]);

```

## 其他运算符

- `sizeof()`：返回数据类型的大小。
- `typeof()`：返回 class 的`Type`对象。
- `&`：返回变量的地址。
- `*`：变量的指针。
- `is`：检测对象类型兼容性，并返回结果（`true`或`false`）。
- `as`：检测对象类型兼容性，并返回转换后结果，不兼容则返回`null`。

## 优先级

运算符的优先级确定表达式中项的组合顺序。在表达式中，较高优先级的运算符会优先被计算。可以通过`()`控制优先级。

| :--------- | :------------------------------ | :------- |
| 后缀       | () [] -> . ++ - -                 | 从左到右 |
| 一元       | + - ! ~ ++ - - (type)* & sizeof   | 从右到左 |
| 乘除       | * / %                             | 从左到右 |
| 加减       | + -                               | 从左到右 |
| 移位       | << >>                             | 从左到右 |
| 关系       | < <= > >=                         | 从左到右 |
| 相等       | == !=                             | 从左到右 |
| 位与 AND   | &                                 | 从左到右 |
| 位异或 XOR | ^                                 | 从左到右 |
| 位或 OR    | \|                                | 从左到右 |
| 逻辑与 AND | &&                                | 从左到右 |
| 逻辑或 OR  | \|\|                              | 从左到右 |
| 条件       | ?:                                | 从右到左 |
| 赋值       | = += -= *= /= %=>>= <<= &= ^= \|= | 从右到左 |
