## 1、删除排序数组中的重复项

给定**升序**数组`nums`，删除重复元素以使每个元素只出现一次并保持元素相对顺序不变，返回删除后新数组的长度。

要求：不使用额外的数组空间，即必须在**原地**操作数组并在只能使用O(1)额外空间的条件下完成。在删除重复项之后有`k`个元素，那么`nums`的前`k`个元素应该保存最终结果，不需要考虑数组中超出新长度后面的元素。

提示：

```C#
1 <= nums.length <= 3 * 10^4
-10^4 <= nums[i] <= 10^4
nums已按升序排列
```

示例：

```C#
输入：nums = [1,1,2]
输出：2, nums = [1,2,_]
解释：返回新数组长度2，并将原数组nums前两个元素修改为[1,2]。
```

### 双指针

因为数组已按升序排列，因此重复元素一定是相邻的，所以只需要遍历一次数组并在原数组之上进行操作即可。

使用快、慢双指针，其中通过快指针遍历原数组，慢指针指示新数组末尾。当遇到新元素（即快指针指向的值不等于慢指针指向的值）时，将该元素添加到新数组末尾。

- 时间复杂度：O(n)。遍历数组所需要的时间。
- 空间复杂度：O(1)。使用一个变量存储新数组长度。

``` C#
int RemoveDuplicates(int[] nums)
{
    // 检查
    if (nums == null || nums.Length == 0) return 0;
    
    // 慢指针初始化
    int slow = 0;
    // 快指针遍历数组
    for (int fast = 1; fast < nums.Length; ++fast)
    {
        // 遇到未重复元素时将该元素添加到慢指针处
        if (nums[fast] != nums[slow])
            nums[++slow] = nums[fast];
    }
    // 新数组长度
    return slow + 1;
}
```

或者使用另一种解法，其原理与双指针相同。

``` C#
int RemoveDuplicates(int[] nums)
{
    // 检查
    if (nums == null || nums.Length == 0) return 0;
    
    // 重复元素个数
    int count = 0;
    // 遍历数组
    for (int i = 1; i < nums.Length; ++i)
    {
        // 遇到重复元素时累计重复元素个数
        if (nums[i] == nums[i - 1])
            ++count;
        // 遇到未重复元素时将该元素往前挪
        else
            nums[i - count] = nums[i];
    }
    // 新数组长度
    return nums.Length - count;
}
```

## 2、数组是否存在重复元素

给定整数数组`nums`，如果任一值在数组中至少出现两次，返回`true`，如果数组中元素各不相同则返回`false`。

提示：

```C#
1 <= nums.length <= 10^4
-10^9 <= nums[i] <= 10^9
```

示例：

```C#
输入：nums = [1,2,1]
输出：true
```

### 排序

将数组排序后，重复元素一定是相邻的，所以只需要遍历已排序数组，判断相邻两元素是否相等即可。

- 时间复杂度：O(nlogn)。对数组排序需要的时间。
- 空间复杂度：O(logn)。排序时递归所占用的栈空间。

``` C#
bool ContainsDuplicate(int[] nums)
{
    // 检查
    if (nums == null || nums.Length <= 1) return false;
    
    // 排序
    Array.Sort(nums);
    // 遍历数组
    for (int i = 1; i < nums.Length; ++i)
    {
        // 有重复元素
        if (nums[i - 1] == nums[i])
            return true;
    }
    // 无重复元素
    return false;
}
```

### 哈希表

遍历数组时将出现的元素插入哈希表中。如果发现哈希表中已含有该元素，则说明数组中存在重复元素。

- 时间复杂度：O(n)。遍历数组需要的时间。
- 空间复杂度：O(n)。哈希表所需要的空间。

``` C#
bool ContainsDuplicate(int[] nums)
{
    // 检查
    if (nums == null || nums.Length <= 1) return false;
    
    // 哈希表
    HashSet<int> existing = new HashSet<int>();
    // 遍历数组
    for (int i = 0; i < nums.Length; i++)
    {
        // 哈希表中存在当前元素即数组中有重复元素
        if (existing.Contains(nums[i]))
            return true;
        // 不存在当前元素
        else
            existing.Add(nums[i]);
    }
    // 无重复元素
    return false;
}
```

## 3、连续子数组最大和

给定整数数组`nums`，找出所有连续子数组（子数组至少包含一个元素）中和的最大值。

提示：

```C#
1 <= nums.length <= 10^5
-10^4 <= nums[i] <= 10^4
```

示例：

```C#
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组[4,-1,2,1]的和最大，为6。
```

### 动态规划

设数组`nums`的长度为`n`，求解其连续子数组最大和问题f(n)等价于求解所有长度为`i`的数组的连续子数组最大和问题`f(i)`的最大值，即`Max(f(i))`。而`f(i)`则可以转化为`f(i-1)`和`nums[i]`的问题。当`f(i-1)+nums[i]`小于`nums[i]`时，应从`nums[i]`开始构成新的连续子数组，`f(i)`等于`nums[i]`；反之将`nums[i]`加入原连续子数组，`f(i)`等于`f(i-1)+nums[i]`，即`f(i)`等于`Max(nums[i],f(i-1)+nums[i])`。

根据以上分析，可以从头遍历数组，依次求得长度为`i+1`的子数组的`f(i)`，其中`f(0)=nums[0]`。需要使用长度为`n`的数组`dp`存储求得的`f(i)`。

- 时间复杂度：O(n)。遍历一次数组以求出所有`f(i)`。
- 空间复杂度：O(n)。使用数组`dp`存储所有`f(i)`。

``` C#
int MaxSubArray(int[] nums)
{
    // 检查
    if (nums == null || nums.Length == 0) return 0;
    
    // 临时数组
    int[] dp = new int[nums.Length];
    dp[0] = nums[0];
    // 结果
    int res = nums[0];
    // 遍历数组
    for (int i = 1; i < nums.Length; ++i)
    {
        // 存储f(i)
        dp[i] = Math.Max(nums[i], dp[i - 1] + nums[i]);
        // 判断最大和是否改变
        res = Math.Max(dp[i], res);
    }
    // 返回最大和
    return res;
}
```

由于`f(i)`只和`f(i-1)`有关，所有可以使用`nums`存储`f(i)`，将空间复杂度从O(n)降至O(1)。

``` C#
int MaxSubArray(int[] nums)
{
    // 检查
    if (nums == null || nums.Length == 0) return 0;
    
    // 结果
    int res = nums[0];
    // 遍历数组
    for (int i = 1; i < nums.Length; ++i)
    {
        // 存储f(i)
        nums[i] = Math.Max(nums[i], nums[i - 1] + nums[i]);
        // 判断最大和是否改变
        res = Math.Max(nums[i], res);
    }
    // 返回最大和
    return res;
}
```

### 分治

定义一个操作`Get(a, l, r)`表示查询`a`序列在区间`[l,r]`内的最大子段和。那么原答案就是`Get(nums, 0, nums.Length-1)`。

对于一个区间`[l,r]`，取中间位置`m=(l+r)/2`，并对左子区间`[l,m]`和右子区间`[m+1,r]`分治求解。当递归逐层深入直到区间长度缩小为1的时候，递归开始回升。此时，将左、右子区间的信息合并成区间`[l,r]`的信息。

对于一个区间`[l,r]`，可以维护四个量：

- `lSum`表示`[l,r]`内以`l`为左端点的最大子段和，
- `rSum`表示`[l,r]`内以`r`为右端点的最大子段和，
- `mSum`表示`[l,r]`内的最大子段和，
- `iSum`表示`[l,r]`的区间和。

对于长度为1的区间`[i,i]`，四个量的值都和`nums[i]`相等。对于长度大于1的区间：

- 首先最好维护的是`iSum`，区间`[l,r]`的`iSum`就等于左子区间的`iSum`加上右子区间的`iSum`；
- 对于`[l,r]`的`lSum`，存在两种可能，它要么等于左子区间的`lSum`，要么等于左子区间的`iSum`加上右子区间的`lSum`，二者取大；
- 同理，对于`[l,r]`的`rSum`，它要么等于右子区间的`rSum`，要么等于右子区间的`iSum`加上左子区间的`rSum`，二者取大；
- 对于`[l,r]`的`mSum`，考虑`[l,r]`的`mSum`对应的区间是否跨越`m`：它可能不跨越`m`，即`[l,r]`的`mSum`可能是左子区间的`mSum`或右子区间的`mSum`中的一个；它也可能跨越`m`，可能是左子区间的`rSum`与右子区间的`lSum`的和。三者取大。

这样问题就得到了解决。

- 时间复杂度：O(n)。递归二叉树的渐进时间复杂度。
- 空间复杂度：O(logn)。递归使用的栈空间。

``` C#
int MaxSubArray(int[] nums)
{
    return GetInfo(nums, 0, nums.Length - 1).mSum;
}

// 区间需要维护的信息
public class Status
{
    public int lSum, rSum, mSum, iSum;
    public Status(int lSum, int rSum, int mSum, int iSum)
    {
        this.lSum = lSum;
        this.rSum = rSum;
        this.mSum = mSum;
        this.iSum = iSum;
    }
}

// 将左、右子区间的信息合并为完整区间的信息
public Status PushUp(Status l, Status r)
{
    int iSum = l.iSum + r.iSum;
    int lSum = Math.Max(l.lSum, l.iSum + r.lSum);
    int rSum = Math.Max(r.rSum, r.iSum + l.rSum);
    int mSum = Math.Max(Math.Max(l.mSum, r.mSum), l.rSum + r.lSum);
    return new Status(lSum, rSum, mSum, iSum);
}

// 获取某区间维护的信息
public Status GetInfo(int[] a, int l, int r)
{
    // 递归边界条件
    if (l == r)
        return new Status(a[l], a[l], a[l], a[l]);
    
    // 区间的中间位置
    int m = (l + r) >> 1;
    Status lSub = GetInfo(a, l, m);
    Status rSub = GetInfo(a, m + 1, r);
    return PushUp(lSub, rSub);
}
```

方法二相比于方法一，时间复杂度相同，但由于递归以及需要维护的信息而在时间、空间上不占优势。但方法二可以解决任意区间`[l,r]`的问题。

如果把`[0,n−1]`分治下去出现的所有子区间的信息都用堆式存储的方式记忆化下来，即建成一棵真正的树（线段树），那么就可以在O(logn)的时间内求到任意区间内的答案，甚至可以修改序列中的值，做一些简单的维护，之后仍然可以在O(logn)的时间内求到任意区间内的答案。对于大规模查询的情况下，这种方法的优势便体现了出来。

## 4、两数之和

给定整数数组`nums`和一个整数目标`target`，在数组中找出和为`target`的两个整数并返回二者的下标。

要求：同一元素在答案中不能重复出现。

提示：

```C#
2 <= nums.length <= 10^4
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9
只会存在一个有效答案
```

示例：

```C#
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：nums[0] + nums[1] = 9。
```

### 暴力枚举

遍历数组每一个元素时，在数组中查找是否存在另一个数使得二者之和为`target`。在遍历时，只需要判断当前元素之后的元素即可。

- 时间复杂度：O(n^2)。最差情况下每个元素都被遍历两次。
- 空间复杂度：O(1)。

``` C#
int[] TwoSum(int[] nums, int target)
{
    int n = nums.Length;
    // 遍历数组
    for (int i = 0; i < n; ++i)
    {
        for (int j = i + 1; j < n; ++j)
        {
            if (nums[i] + nums[j] == target)
                return new int[] {i, j};
        }
    }
    return new int[0];
}
```

### 字典

使用字典可以快速查找元素从而降低时间复杂度。在遍历数组时，先在字典中查找是否存在需要的元素，没有则将当前元素加入至字典中。

- 时间复杂度：O(n)。遍历一次数组需要的时间。
- 空间复杂度：O(n)。字典所占用的空间。

``` C#
int[] TwoSum(int[] nums, int target)
{
    // 已遍历元素<元素值，元素索引>
    Dictionary<int, int> elements = new Dictionary<int, int>();
    // 遍历数组
    for (int i = 0; i < nums.Length; ++i)
    {
        if (elements.ContainsKey(target - nums[i]))
        	return new int[] {i, elements[target - nums[i]]};
        else
        {
            // 防止键重复
            if (!elements.ContainsKey(nums[i]))
                elements.Add(nums[i], i);
        }
    }
    return new int[0];
}
```

## 5、合并两个有序数组

给定两个非递减整数数组`nums1`和`nums2`，另有两个整数`m`和`n`，分别表示`nums1`和`nums2`中的元素数目。合并`nums2`到`nums1`中。

要求：合并后的数组不应由函数返回，而是存储在`nums1`中，因此`nums1`的长度为`m+n`。合并后的数组应是非递减排列的。

提示：

```C#
nums1.length == m+n
nums2.length == n
0 <= m,n <= 200
1 <= m+n <= 200
-10^9 <= nums1[i],nums2[j] <= 10^9
```

示例：

```C#
输入：nums1 = [1,2,3,0,0,0], nums2 = [2,5,6]
输出：[1,2,2,3,5,6]
```

### 双指针加临时数组

因为两个数组是有序的，因此可以使用双指针同时遍历两数组，按顺序将元素存放在临时数组中。

- 时间复杂度：O(m+n)。两个数组的元素都要被遍历。
- 空间复杂度：O(m+n)。临时数组的空间开销。

``` C#
void Merge(int[] nums1, int m, int[] nums2, int n)
{    
    // 临时数组
    int[] temp = new int[m + n];
    // 双指针
    int p1 = 0, p2 = 0;
    // 遍历数组
    while (p1 < m || p2 < n)
    {
        int cur;
        // num1已遍历完
        if (p1 == m)
            cur = nums2[p2++];
        // num2已遍历完
        else if (p2 == n)
            cur = nums1[p1++];
        else if (nums1[p1] <= nums2[p2])
            cur = nums1[p1++];
        else
            cur = nums2[p2++];
        temp[p1 + p2 - 1] = cur;
    }
    // 将结果保存到nums1
    temp.CopyTo(nums1, 0);
}
```

### 双指针

已知`nums1`的末尾为空白，因此可以从后向前遍历两数组，将较大元素放在`nums1`最后面。因为`nums1`长度为`m+n`，即使将`nums2`的元素全部放到`nums1`尾部，也不会覆盖`nums1`中未遍历的元素。

- 时间复杂度：O(m+n)。遍历长度为`m+n`的数组需要的时间。
- 空间复杂度：O(1)。不需要额外空间。

``` C#
void Merge(int[] nums1, int m, int[] nums2, int n)
{
    // 双指针
    int p1 = m - 1, p2 = n - 1;
    // 遍历数组
    for (int i = m + n - 1; i >= 0; --i)
    {
        if (p1 < 0)
            nums1[i] = nums2[p2--];
        else if (p2 < 0)
            nums1[i] = nums1[p1--];
        else if (nums1[p1] <= nums2[p2])
            nums1[i] = nums2[p2--];
        else
            nums1[i] = nums1[p1--];
    }
}
```
