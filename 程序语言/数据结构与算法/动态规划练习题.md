## 1、斐波那契数列

> 写一个函数，输入n，求斐波那契（Fibonacci）数列的第n项。答案需要取模1e9+7（1000000007）。
>
> 斐波那契数列定义：斐波那契数列由0和1开始，之后的斐波那契数就是由之前的两数相加而得出。
>
> 如：0，1，1，2，3，5，...

由斐波那契数列定义可知，f(n)=f(n-1)+f(n-2)。

1. 状态定义：一维数组dp，dp[i]为斐波那契数列的第i项；
2. 初始状态：f(0)=0，f(1)=1；
3. 转移方程：dp[i]=dp[i-1]+dp[i-2]；
4. 返回值：dp[n]。

``` C#
int Fibonacci(int n)
{
    if (n == 0) return n;
    int[] dp = new int[n + 1];
    dp[1] = 1;
    for (int i = 2; i < n; i++)
    {
        dp[i] = (dp[i - 1] + dp[i - 2]) % 1000000007;
    }
    return dp[n];
}
```

计算f(n)需要循环n次，时间复杂度为O(n)；借助了数组`dp`保存子问题的解，空间复杂度为O(n)。由于f(n)只与f(n-1)和f(n-2)有关，可以仅使用两个变量交替前进计算，此时动态规划的空间复杂度降低至O(1)。

``` C#
int Fibonacci(int n)
{
    if (n == 0) return n;
    int a = 0, b = 1;
    for (int i = 2; i < n; i++)
    {
        int temp = a;
        a = b;
        b = (b + temp) % 1000000007;
    }
    return b;
}
```

**大数越界**：随着n增大, f(n)会超过`Int32`甚至`Int64`的取值范围，导致最终的返回值错误。

当一个问题只对答案的正确性有要求，而不在乎答案的数值，可能会需要将取值很大的数通过求余变小。

`Int32`取值范围是-2147483648~2147483647，1e9+7是最小的十位质数。模1e9+7，1000000007+1000000007=2000000014，可以保证值永远在`Int32`的范围内。

`Int64`的最大值为`2^63-1`，对于1e9+7来说它的平方不会在`Int64`中溢出。所以在大数相乘时，将操作数都对1e9+7取模，则结果不会溢出。

## 2、青蛙跳台阶问题

> 一只青蛙一次可以跳上1级台阶，也可以跳上2级台阶。求该青蛙跳上一个n级的台阶总共有多少种跳法。答案需要取模1e9+7。

青蛙跳上n阶的总跳法为f(n)，求解f(n)可以分解为跳上f(i-1)阶加跳1步和跳上f(i-2)阶加跳2步，所以f(n)=f(n-1)+f(n-2)。

1. 状态定义：一维数组dp，dp[i]为跳上i级台阶的跳法；
2. 初始状态：f(0)=1，f(1)=1；
3. 转移方程：dp[i]=dp[i-1]+dp[i-2]；
4. 返回值：dp[n]。

``` C#
int NumWays(int n)
{
    if (n == 0) return 1;
    int a = 1, b = 1;
    for (int i = 2; i <= n; i++)
    {
        int temp = a;
        a = b;
        b = (b + temp) % 1000000007;
    }
    return b;
}
```

时间复杂度O(n)，空间复杂度O(1)。

## 3、连续子数组的最大和

> 输入一个整型数组，数组中的一个或连续多个整数组成一个子数组。求所有子数组的和的最大值。
>
> 要求时间复杂度为O(n)。

设长度为n的数组nums，其连续子数组最大和f(n)，则求解f(n)可以转化为求解Max{f(n-1),nums[n]+f(n-1)}。如果f(n-1)小于0，则其对f(n)产生负贡献，即nums[n]+f(n-1)还不如nums[n]大。

1. 状态定义：一维数组dp，dp[i]为nums[i]结尾的连续子数组最大和；
2. 转移方程：dp[i]=nums[n]+dp(i-1)，dp(i-1)>=0；dp[i]=nums[n]，dp(i-1)<0；
3. 初始状态：dp[0]=nums[0]，无元素数组的连续子数组最大和为0；
4. 返回值：dp数组中的最大值。

结果dp[i]仅与nums[n]和dp(i-1)有关，因此可以使用nums存储dp[i]，将空间复杂度从O(n)降低至O(1)。

``` C#
int MaxSubArray(int[] nums)
{
    int res = nums[0];
    for (int i = 1; i < nums.Length; i++)
    {
        nums[i] += Math.Max(nums[i - 1], 0);
        res = Math.Max(res, nums[i]);
    }
    return res;
}
```

时间复杂度O(n)，空间复杂度O(1)。

## 4、把数字翻译成字符串

> 给定一个数字，按如下规则把它翻译为字符串：0翻译成“a”，1翻译成“b”，...，10翻译成“k”，...，25翻译成“z”。一个数字可能有多个翻译。
>
> 实现一个方法，计算一个数字有多少种不同的翻译方法。

设n位数字num，其翻译方法共有f(n)种，将求解f(n)分解为f(n-1)与最后一位数字的种数加f(n-2)与最后两位数字的种数。当最后两位数字小于10或大于25时，只有一种方法翻译此两位数字，即f(n)=f(n-1)；大于等于10并且小于等于25时有两种方法翻译此两位数字，其中分开翻译的方法包含在f(n-1)之中，因此只需要加上整体翻译的种数，即f(n)=f(n-1)+f(n-2)。

1. 状态定义：一维数组dp，dp[i]为num第i位数字的翻译方法数；
2. 转移方程：dp[i]=dp[i-1]，0<=后两位<10或25<后两位<=99；dp[i]=dp[i-1]+dp[i-2]，10<后两位<25；
3. 初始状态：dp[0]=dp[1]=1，无数字翻译方法也是1。
4. 返回值：dp[n]。

结果仅与dp[i-1]和dp[i-2]有关，因此可以使用两个变量记录并交替前进。此题动态规划具有对称性，即从左向右与从右向左结果相同。

``` C#
int TranslateNum(int num)
{
    if (num < 10) return 1;
    int a = 1, b = 1; // 两个变量记录dp[i-1]和dp[i-2]交替前进
    int x = num % 10, y = x;
    while (num > 9)
    {
        num /= 10;
        x = num % 10;
        int temp = 10 * x + y;
        int c = temp >= 10 && temp <= 25 ? a + b : a;
        b = a;
        a = c;
        y = x;
    }
    return a;
}
```
