# 自动寻路系统

## AI

人工智能（Artificial Intelligence，AI）是研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新兴科学技术。AI可以提高游戏可玩性、激发玩家挑战欲望。游戏中的AI通常指怪物的巡逻及寻路等机制。

常见的寻路方法：路点寻路；A星寻路；网格寻路。

## 导航网格NavMesh寻路实现

导航网格NavMesh是3D游戏世界中用于实现动态物体自动化寻路的一种技术，将游戏中复杂的结构组织关系简化为带有一定信息的网格，在这些网格基础上通过一系列计算实现自动寻路。导航时，只需要给导航物体挂载导航组件，导航物体便会自行根据目标的来寻找最直接的路线，并沿着该线路到达目标点。

实现过程为：1、烘焙寻路路面；2、给寻路对象添加代理组件NavMeshAgent；3、程序实现寻路。

### 烘焙寻路路面

1、先将路边标记为Navigation Static导航静态物体，此后该物体无法移动。2、打开导航面板，在烘焙Bake选项卡中，设置相关参数后烘焙路面信息。

Object选项卡：

- Scene Filter：All；Mesh Renderers；Terrains。
- Navigation Static导航是否静态。
- Generate OffMeshLinks是否生成断开网格连接：实现跳跃时勾选。
- Navigation Area导航区域。

Bake选项卡参数：

- Agent Radius代理半径。
- Agent  Height代理高度。
- Max Slope最大上坡高度。
- Step Height可上台阶高度。
- Drop Height降落高度。
- Jump Distance跳跃距离。

### NavMeshAgent组件

网格导航代理组件。

- Agent Type代理类型：Humanoid人形。
- Base Offset基准偏移：包围盒（区别两个代理，防止穿模）的偏移量。
- Speed速度。
- Angular Speed角速度：转向弧度。
- Acceleration加速度。
- Stopping Distance停止距离。
- Auto Braking到达目标后是否立即停止。
- Radius包围盒半径。
- Height包围盒高度。
- Quality障碍回避质量。
- Priority躲避优先级：值越小，通过优先级越高。
- Auto Traverse Off Mesh Link自动使用Mesh Link：跳跃时使用。
- Auto Repath自动更新路径。
- Area Mask区域遮罩：分区域寻路。

### Nav Mesh Obstacle组件

Nav Mesh Obstacle组件可以让可移动对象实现动态障碍，而不像静态烘焙一样无法移动。

- Shape包围盒形状。

- Center中心位置。

- Radius半径。

- Height高度。

- Size尺寸。

- Carve挖洞模式：实时烘培移动对象的障碍，是寻路对象不考虑该路径。

  - Move Threshold移动阈值：当前物体移动距离超过该值后再次挖洞，越大越迟钝。
  - Time To Stationar时间阈值：移动多久后再次挖洞。
  - Carve Only Statio移动时是否挖洞。

### Off Mesh Link组件

  在对象之间生成OffMeshLink脱离网格连接，以便跳跃。

- Start起点对象。
- End终点对象。
- Cost Override消耗重写。
- Bi Directional是否双向。
- Activated是否激活。
- Auto Update Position是否自动更新连接的位置。
- Navigation Area区域遮罩。

### 程序实现

``` C#
NavMeshAgent agent;

void Start()
{
    agent = GetComponent<NavMeshAgent>();
}

void Update()
{
    agent.SetDestination(target.position); // 设置目标点，实现寻路
}
```

### 分区域寻路

先对场景设置区域后烘焙信息，再设置寻路对象代理组件Nav Mesh Agent中区域遮罩（二进制设置时0表示Nothing，1表示Everything）。

消耗Cost是路径计算的优先值；自动寻路时，总是优先选择Cost最小的路径。

### 新组件

Nav Mesh Surface烘焙信息组件：将窗口烘焙移到组件身上（可以使用脚本控制烘焙）。一个对象上可以有多个Nav Mesh Surface组件，可以设置不同的代理类型（根据不同的代理类型可以烘焙出不同的路面效果），可以烘焙垂直面（模拟2D）。

- Agent Type代理类型。
- Collect Objects集合对象：All所有无代理对象；Volume指定烘焙范围；Children烘焙自身及子物体。
- Include Layer烘焙的层。
- Use Geometry：Render Meshes基于网格烘焙；Physics Colliders基于物理碰撞。

Nav Mesh Modifier Volume导航网格改性组件：修改当前对象上某指定区域的烘焙，对烘焙路面进行微调（修改区域类型和范围）。

- Size尺寸。
- Center中心位置。
- Area Type区域类型。
- Affected Agents应用于哪个代理。

Nav Mesh Modifier导航网格改性组件：修改当前对象的烘焙。

- Ignore From Build忽视Build烘焙。
- Override Area重写区域。
- Affected Agents应用于哪个代理。

Nav Mesh Link导航网格连接：连接多个具有相同代理类型的Nav Mesh Surface。

- Agent Type代理。
- Start Point起始点。
- End Point终点。
- Width桥的宽度。
- Cost Modifier消耗修改。
- Auto Update Position是否自动更新连接的位置。
- Bidirectional是否双向。
- Area Type区域类型。

Local Nav Mesh Builder本地导航烘焙组件：在包围盒内有Nav Mesh Source Tag的组件的对象可以参与实时烘焙。

## A星寻路

A星是一种启发式算法，即对每个搜索的位置进行评估，也就是把找的位置离目标的距离当作找点的依据，任何猜测这个点是否是最佳。

为了寻找最佳路点，可以规定G（从起点，沿产生的路径移动到网格上指定方格的距离）、H（从网格上指定放个移动到终点的预估移动距离）、F（G+H），F最小的点可认为是该选的点。

优点：与贪婪算法（适合动态规划，寻找局部最优解，不保证最优解）不同，A星是静态网格中求解最短路的最有效方法，也是耗时的算法，不宜寻路频繁的场合，适合需求精确的场合，可控制寻路；与启发式搜索一样，能根据改变网格密度、网格耗散来调整精确度。

A星寻路通常用于策略游戏的策略搜索和方块格子游戏中的格子寻路。
