## 数学工具

`Math`是C#提供的用于数学计算的工具类，位于System命名空间中。`Mathf`是Unity提供的用于数学计算的工具结构体，位于UnityEngine命名空间中。`Mathf`不仅包含了数学计算方法，还提供了一些更适合游戏开发的方法。

### 常用方法

- 常量：PI，Infinity，NegativeInfinity，Deg2Rad，Rad2Deg，Epsilon。
- 绝对值Abs，向上取证CeilToInt，向下取整FloorToInt，钳制范围Clamp，四舍五入RoundToInt，最大值Max，最小值Min，次方Pow，平方根Sqrt，是否是2的幂IsPowerOfTwo，正负符号Sign。
- 插值`Lerp(start, end, t)`，其中t为插值系数，其结果为start+(end-start)*t。用法1：`start = Lerp(start, end, Time.deltaTime)`，每帧改变start，变化速度先快后慢，结果无限接近end但不会达到。用法2：`t += TIME.deltaTime; Lerp(start, end, t)`，每帧改变t的值，变化匀速，当t大于1时达到end。

## 三角函数

### 角度和弧度

两条射线从圆心向圆周射出，形成一个夹角和夹角正对的一段弧。当弧长为圆周的360分之一时，夹角为1度（Degree）；弧长等于圆的半径时，夹角为1弧度（Radian）。

PI弧度 = 180度，1弧度 = 180/PI度，1度 = PI/180弧度。

角度转弧度：弧度 = 角度 * PI / 180，Deg2Rad = 0.01745。

弧度转角度：角度 = 弧度 * 180 / PI，Rad2Deg = 57.3。

### 三角函数

三角函数建立了角与边的关系，通常用于已知一边一角，求另一边。在直角三角形中：

- 正弦Sin = 对边 / 斜边。
- 余弦Cos = 邻边 / 斜边。
- 正切Tan = 对边 / 邻边。
- 余切Cot = 邻边 / 对边 = 1 / Tan。
- 正割Sec = 斜边 / 邻边 = 1 / Cos。
- 余割Csc = 斜边 / 对边 = 1 / Sin。

### 反三角函数

通常用于已知两边，求角。在直角三角形中：

- 反正弦arcsin 对边 / 斜边 = 角度。 
- 反余弦arccos 邻边 / 斜边 = 角度。
- 反正切arctan 对边 / 邻边 = 角度。
- 反余切arccot 邻边 / 对边 = 角度。
- 正割arcsec 斜边 / 邻边 = 角度。
- 余割arccsc 斜边 / 对边 = 角度。

## 坐标系

世界坐标系是相对于世界的，物体的position、rotation、eulerAngles、lossyScale都是世界坐标系的。

本地坐标系是相对于父物体的，物体的localPosition、localRotation、localEulerAngles、localScale都是本地坐标系的。

屏幕坐标系是相对于屏幕左下角的屏幕位置，Input.mousePosition、Screen.width、Screen.height。

视口坐标系是摄像机上视口显示范围。

## 向量

向量是一个有大小（模）和方向的物理量，各分量代表相应轴向的位移，用于描述物体在空间的位置和方向。两点决定一向量，即终点减起点。

模表示向量的大小（意义），是各分量的平方和的平方根。

获取向量的方向也称“标准化向量”或“归一化向量”，即获取该向量的单位向量。单位向量即模长为1的向量。其几何意义是将该向量伸缩以使其模长为1，公式为向量除以向量的模。

向量支持加、减、与标量的乘除、点乘、叉乘。

**加法**公式：各相应分量相加。

几何意义：向量a与向量b相加（`a+b`），结果为将两向量首尾相连，以向量a的起点为起点，以向量b的终点为终点的向量，方向由a指向b。

应用：移动物体。

**减法**公式：各相应分量相减。

几何意义：向量a与向量b相减（`a-b`），结果为将两向量共起点，以向量b的终点为起点，以向量a的终点为终点的向量，方向由b指向a。

应用：获取相对方向。

**向量与标量的乘除**公式：各分量分别乘/除标量，得到的结果还是一个向量。

几何意义：对向量模长的缩放。

**点乘**又称“点积”、“内积”。通常用于求两向量的夹角。

公式：各相应分量之积的和，结果为标量。

几何意义：点乘的结果等于两向量模长与其夹角余弦值的积；一个向量在另一个向量上的投影的模乘以另一个向量的模。

点乘结果只能得到0-180度之间的夹角。对于标准化过的向量，点乘结果为两向量模长与其夹角余弦值的积；若两向量方向相同则结果为1，相反结果为-1，垂直时结果为0。

**叉乘**又叫“叉积”、“外积”。通常用于创建平面的法向量、判断两向量的相对位置。

公式：以i，j，k和两向量组成的矩阵，结果是一个向量。

几何意义：叉乘的结果为两向量组成的平面的垂直向量，该向量的模长为两向量的模长之积再乘以二者夹角的正弦值，方向可以通过“右手螺旋定则”确定，即右手四指方向为第一个向量对第二个向量的旋转方向，大拇指方向便是叉乘结果的方向。

## 欧拉角

欧拉角通过三个角度来存储方位。X与Z沿自身坐标系旋转，Y沿世界坐标系旋转。

优点：仅使用三个数表达方位，占用空间小；沿坐标轴旋转的单位为角度，符合人的思考方式；任意三个数都是合法的，不存在非法的欧拉角。

缺点：表达方式不唯一（因为不存在非法的欧拉角，因此对于同一个方位可以使用多个欧拉角描述，因此无法判断多个欧拉角代表的角位移是否相同），Unity规定X轴旋转范围[-90,90]度，Y和Z轴旋转范围[0,360]度；**万向节死锁**（当物体沿X轴转了正负90度时，该物体自身坐标系的Z轴与世界坐标系的Y轴重合，此时再沿Y或Z轴旋转时将失去一个自由度），Unity规定，万向节死锁时，沿Y轴旋转完成绕竖直轴的全部旋转， 即Z轴旋转始终为0。

## 四元数

四元数（单位四元数，Quaternion）是四维空间中一个超球上面的点，满足w2+x2+y2+z2=1；而纯四元数是四维空间在w=0时的一个子空间的点，形式为{0,q}，特别注意的是纯四元数与四元数是不同的概念。

四元数在3D图形学中代表旋转（轴角旋转），由一个三维向量[x,y,z]和一个标量w组成。x、y、z、w的取值在[-1,1]之间。

四元数是复数虚部扩展的结果，复数的虚部为1个，而四元数虚部有3个，且两两互相正交，其中实部是w，而虚部为x、y、z。对于旋转单位轴V和旋转弧度θ：

- `x = sin(θ/2)V.x`。
- `x = sin(θ/2)V.x`。
- `x = sin(θ/2)V.x`。
- `w = cos(θ/2)`。

四元数自由度并没有四个维度，由于存在w2+x2+y2+z2=1这个约束，它的自由度其实只有3，且每个四元数可以对应一个特征向量，即n。

优点：避免万向节死锁；

缺点：难以使用，不能单独修改某个分量；存在不合法的四元数。

**两个四元数相乘**表示组合旋转效果。

**四元数左乘向量**表示将向量按照四元数表示的角度旋转。
