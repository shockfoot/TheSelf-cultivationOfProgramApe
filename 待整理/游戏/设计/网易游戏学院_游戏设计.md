# 游戏设计

## 第一章、游戏开发者的责任

游戏不能只考虑好玩、吸引人，还要考虑：

- 游戏的设计必须满足国家法律法规的要求。
- 游戏设计的玩法内容、故事背景等需要符合社会的公序良俗和社会正向的价值观。
- 需要引导未成年人有良好的游戏习惯和健康的生活。
- 宣扬我国传统文化，学习国外优秀文化。

防沉迷措施：

- 实名认证：对确定为未成年人身份的、实名信息不规范的和验证未通过的用户纳入网络游戏防沉迷系统。
- 家长监护：通过监护关系、账号归属判断后，依据资料证明的充分和可信程度，获取全部或部分帮助和服务，为家长提供一种实施监护的渠道。

## 第二章、策划责任制与研发过程

策划责任制追求策划能把所有参与人员调动，发挥所有参与人员的积极性和创造力。

研发制作过程：

1. 分析需求：确认设计目的、用户目标、内容范围等。
2. 分解需求：分析设计难度，寻找其他游戏产品或非游戏产品参考，头脑风暴。
3. 撰写策划文档。
4. 研发制作。
5. 内部测试。
6. 发布：发布后需要跟踪数据及舆情。
