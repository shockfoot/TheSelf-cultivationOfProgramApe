# 类型

Python中标准数据类型有数字、字符串、布尔、列表、元组、集合和字典等。其中，不可变数据类型有数字、字符串、元组，可变数据类型有列表、集合、字典。此外，还有一些高级数据类型如字节数组等。

可以使用`type()`获取变量所指对象的类型，`isinstance()`判断变量所指对象是否为指定类型（子类会被认为是父类类型）。

## 内置类型

### 数字类型

Python支持的数字类型有整型`int`、浮点数`float`、布尔`bool`、复数`complex`。

复数由实部和虚部构成，可以用`a + bj`或`complex(a,b)`表示，其中`a`和`b`都是浮点数。

### 字符串

Python中的字符串使用`'`或`"`包裹，同时使用`\`转义特殊字符。如果不想让`\`发生转移，可以在字符串前加`r`，表示原始字符串。

```python
print(r"Ru\noob") # Ru\noob
```

字符串可以使用索引获取单个字符（Python中没有单独的字符类型，一个字符就是长度为1的字符串）。索引值从右侧以0开始，从末尾以-1开始。此外，可以通过索引截取字符串。

```python
变量[头下标:尾下标]
```

需要注意的是，Python中字符串是不可变的，对一个位置进行赋值会导致报错。

### 布尔类型

布尔类型即`True`或`False`。

`bool`是`int`的子类，`True`（值为1）和`False`（值为0）可以和数字一起运算。

可以使用`bool()`函数将其他类型的值转换为布尔值。以下值在转换为布尔值时为`False`：`None`、`False`、零 (0、0.0、0j)、空序列（如`''`、`()`、`[]`）和空映射（如 `{}`）。其他所有值转换为布尔值时均为`True`。

### 列表

列表（List）是Python中使用最频繁的数据类型。列表可以完成大多数集合类的数据结构实现。

**列表中元素的类型可以不相同**，它支持数字，字符串甚至可以包含列表（所谓嵌套）。列表是写在方括号`[]`之间、用逗号`,`分隔开的元素列表。

和字符串一样，列表同样可以被索引和截取，列表被截取后返回一个包含所需元素的新列表。列表的截取还可以接收第三个参数，表示截取的步长，步长为负数时表示逆向。

```python
number = [1, 2, 3, 4, 5]

print(number[0::2]) # [1, 3, 5]
print(number[-1::-1]) # [5, 4, 3, 2, 1]
```

与字符串不同的是，列表中的元素是可以改变的。

### 元组

元组（Tuple）与列表类似，但其中的元素不能修改。元组写在小括号`()`里，元素之间用逗号隔开。元组的元素类型也可以不相同。实际上，可以将字符串看作是特殊的元组。

虽然元组的元素不可改变，但可以包含可变的对象，如列表。

构造包含0个或1个元素的元组比较特殊，需要一些额外的语法规则。

```python
tup1 = () # 空元组
tup2 = (20,) # 一个元素，需要在元素后添加逗号
```

> 创建只有一个元素的元组，需要注意在元素后面添加一个逗号，以区分它是一个元组而不是一个普通的值，这是因为在没有逗号的情况下，Python会将括号解释为数学运算中的括号，而不是元组的表示。

### 集合

Python中的集合（Set）是一种无序、可变的数据类型，用于存储唯一的元素。集合中的元素不会重复，并且可以进行交集、并集、差集等常见的集合操作。集合使用大括号`{}`表示，元素之间用逗号`,`分隔。另外，也可以使用`set()`函数创建集合。注意，创建一个空集合必须用`set()`而不是`{ }`，因为`{ }`是用来创建一个空字典。

```python
a = set('abracadabra')
b = set('alacazam')

print(a - b)     # a 和 b 的差集
print(a | b)     # a 和 b 的并集
print(a & b)     # a 和 b 的交集
print(a ^ b)     # a 和 b 中不同时存在的元素
```

### 字典

字典（Dictionary）是无序的对象集合，且通过键来存取的元素。字典是一种映射类型，字典用`{ }`标识，它是一个无序的键对的集合。键必须是不可变类型。在同一个字典中，键必须唯一。另外，也可以使用`dict()`函数创建字典。

```python
dict = {}
dict['one'] = "1 - Python"
dict[2]     = "2 - CPP"

tinydict = {'name': 'Python', 'code':1}

dict([('Python', 1), ('CPP', 2), ('CS', 3)])
```

### 字节数组

在Python 3中，字节数组表示不可变的二进制序列。与字符串类型不同的是，字节数组的元素是整数值（0-255）。

字节数组类型通常用于处理二进制数据，比如图像文件、音频文件、视频文件等等。在网络编程中，也经常使用字节数组类型来传输二进制数据。

创建字节数组对象的方式有多种，最常见的方式是使用`b`前缀。此外，也可以使用`bytes()`函数将其他类型的对象转换为字节数组类型。`bytes()`函数的第一个参数是要转换的对象，第二个参数是编码方式，如果省略第二个参数，则默认使用UTF-8编码。

```python
x = b"hello"
y = x[1:3]  # 切片操作，得到 b"el"
z = x + b"world"  # 拼接操作，得到 b"helloworld"
```

## 类型转换

Python数据类型转换可以分为两种：隐式转换和显示转换。

在隐式类型转换中，Python会自动将一种数据类型转换为另一种数据类型。通常在对两种不同类型的数据进行运算时，较低数据类型（如整数）就会转换为较高数据类型（如浮点数）以避免数据丢失。

在显式类型转换中，用户将对象的数据类型转换为所需的数据类型。一般情况下只需要将数据类型作为函数名即可。以下几个内置的函数可以执行数据类型之间的转换。这些函数返回一个新的对象，表示转换的值。

| 函数 | 描述 |
| --- | --- |
| `int(x[, base=10])` | 将x转换为整型，`base`为进制数，默认为十进制。 |
| `float(x)` | 将x转换为浮点数。 |
| `complex(real[, imag])` | 创建一个复数。如果第一个参数为字符串，则不需要指定第二个参数。 |
| `str(x)` | 将x转换为字符串。 |
| `repr(x)` | 将x转换为表达式字符串。 |
| `eval(str)` | 用来计算在字符串中的有效Python表达式，并返回一个对象。 |
| `tuple(s)` | 将序列s转换为元组。 |
| `list(s)` | 将序列s转换为列表。 |
| `set(s)` | 将序列s转换为可变集合。 |
| `dict(d)` | 将键值对元组序列d转换为字典。 |
| `frozenset(s)` | 将s转换不可变集合。 |
| `chr(x)` | 将整数x转化为字符。 |
| `ord(x)` | 将字符x转换为它的整数值。 |
| `hex(x)` | 将整数x转换为十六进制字符串。 |
| `oct(x)` | 将整数x转换为八进制字符串。 |

> 字符串、列表和元组属于序列（Sequence）。
