## 简介

动态规划是算法与数据结构的重难点之一，其包含了**分治思想**、**空间换时间**、**最优解**等多种基石算法思想。

## 动态规划特点

**分治**是算法中一种基本思想，通过*将原问题分解为子问题，不断递归地将子问题分解为更小的子问题，并通过组合子问题的解得到原问题的解*。

类似于分治算法，动态规划也通过组合子问题的解得到原问题的解。不同的是，适合用动态规划解决的问题具有**重叠子问题**和**最优子结构**两大特性。

### 重叠子问题

动态规划的子问题是有重叠的，即各个子问题中包含重复的更小子问题。若使用暴力法穷举，求解这些相同子问题会产生大量的重复计算，效率低下。

动态规划在第一次求解某子问题时，会将子问题的解保存；后续遇到重叠子问题时，则直接通过查表获取解，保证每个*独立子问题只被计算一次*，从而降低算法的时间复杂度。

### 重叠子问题示例：斐波那契数列

> 斐波那契数列[0, 1, 1, 2, 3, 5, 8, 13, ...]，其数学定义：F~0~ = 0；F~1~ = 1；F~n~ = F~n-1~ + F~n-2~。
>
> 题目：求取第n个斐波那契数（从第 0 个斐波那契数开始）。

设斐波那契数列第n个数字为f(n)。根据数列定义，f(n)=f(n−1)+f(n−2)，...，且f(0)=0，f(1)=1。可将求解f(n)化解为求f(n-1)，...，f(0)等子问题。

#### 方法1：暴力递归

很容易联想到使用分治思想求取f(n)，即将求f(n)分解为求f(n−1)和f(n−2)，向下递归至f(1)和f(0)，最终组合这些子问题求取f(n)。

``` C#
int Fibonacci(int n)
{
    if (n == 0) return 0;
    if (n == 1) return 1;
    return Fibonacci(n - 1) + Fibonacci(n - 2); // 分解为两个子问题求解
}
```

执行一次`Fibonacci()`方法的时间复杂度为O(1)，暴力递归求斐波那契数形成的二叉树节点数为2^n^个，因此总时间复杂度为O(2^n^)。此方法效率低下，随着n的增长呈指数级爆炸。

#### 方法二：记忆化递归

观察发现，暴力递归中子问题多数为重叠子问题，如f(n)=f(n-1)+f(n-2)，f(n-1)=f(n-2)+f(n-3)，重复计算f(n-2)。这些重叠子问题产生大量递归树节点。

实际上，可在递归中第一次求解子问题时将其保存，后续递归中再次遇到相同子问题时直接访问内存赋值即可。

``` C#
int FibonacciMemorized(int n)
{
    int[] dp = new int[n + 1]; // 用于保存f(0)至f(n)问题的解
    return Fibonacci(n, dp);
}

int Fibonacci(int n, int[] dp)
{
    if (n == 0) return 0;
    if (n == 1) return 1;
    if (dp[n] != 0) return dp[n]; // 若f(n)已经计算过，直接返回记录的解
    dp[n] = Fibonacci(n - 1, dp) + Fibonacci(n - 2, dp); // 记录f(n)
    return dp[n];
}
```

应用记忆化递归方法后，递归树中绝大部分节点被剪枝。此时，`Fibonacci()`方法调用次数从2^n^指数级别降低至n线性级别，时间复杂度大大降低。借助了数组`dp`保存子问题的解，空间复杂度为O(n)。

#### 方法三：动态规划

递归本质上是基于分治思想的从顶至底的解法。借助记忆化递归思想，可应用动态规划从底至顶求取f(n)。

``` C#
int Fibonacci(int n)
{
    if (n == 0) return 0;
    int[] dp = new int[n + 1];
    dp[1] = 1; // 初始化f(0)和f(1)
    for (int i = 2; i <= n; i++) // 状态转移求取f(2), ..., f(n)
    {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

借助了数组`dp`保存子问题的解，空间复杂度为O(n)。由于f(n)只与f(n-1)和f(n-2)有关，可以仅使用两个变量交替前进计算，此时动态规划的空间复杂度降低至O(1)。

``` C#
int Fibonacci(int n)
{
    if (n == 0) return 0;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) // 状态转移求取f(2), ..., f(n)
    {
        int temp = a;
        a = b;
        b = b + temp;
    }
    return b;
}
```

#### 小结

记忆化递归和动态规划本质思想是一致的，是对斐波那契数列定义的不同表现形式。

- 记忆化递归是从顶至底：求f(n)需要f(n-1)和f(n-2)，...，求f(2)需要f(1)和f(0)，而二者已知。
- 动态规划是从底至顶：已知f(1)和f(0)组合得到f(2)，...，将f(n-1)和f(n-2)组合得到f(n)。

斐波那契数列问题不包含最优子结构，只需要计算每个子问题的解，避免重复计算而不需要从子问题组合中选择最优组合。

### 最优子结构

如果一个问题的最优解可以由其子问题的最优解组合构成，并且这些子问题可以独立求解，那么称此问题具有最优子结构。

动态规划从基础问题的解开始，不断*迭代组合、选择子问题的最优解*，最终得到原问题最优解。

### 最优子结构实例：蛋糕最高售价

> 不同重量的蛋糕有不同的售价，分别为：
>
> 重量：0  1  2  3  4  5  6
>
> 售价：0  2  3  6  7 11 15
>
> 题目：给定重量为n的蛋糕，应如何切分使达到最高总售价。

设重量为n的蛋糕售价p(n)，切分的最高总售价为f(n)。可将求解f(n)分解为求解f(n-1)，...，f(0)等子问题。对于本题，重量为n的蛋糕最高售价可切分为n种组合，即重量为0（或1，...，n-1）蛋糕最高售价加上n（或n-1，...，1）剩余重量蛋糕的售价。从这些组合中，售价最高的组合便是原问题的解f(n)。这便是本题的最优子结构。找出最优子结构后，可构建状态转移方程：`f(n)=max(f(i)+p(n-i))`。

#### 方法一：暴力递归

根据状态转移方程，可以使用暴力递归解决。

``` C#
// priceList为蛋糕价格列表
int MaxCakePrice(int n, int[] priceList)
{
    if (n <= 1) return priceList[n];
    int result = 0;
    for (int i = 0; i < n; i++) // 从n种组合中选择最高售价的组合作为f(n)
    {
        result = Math.Max(result, MaxCakePrice(i, priceList) + priceList[n - i]);
    }
    return result;
}
```

其时间复杂度为指数级O(2^n^)。

#### 方法二：记忆化递归

同样，暴力递归树中存在大量重叠子问题，可通过记忆化处理避免重复计算。

``` C#
int MaxCakePrice(int n, int[] priceList)
{
    int[] dp = new int[n + 1]; // 记录f(0)，...，f(n-1)的值
    return MaxCakePriceMemorized(n, priceList, dp);
}

int MaxCakePriceMemorized(int n, int[] priceList, int[] dp)
{
    if (n <= 1) return priceList[n];
    int result = 0;
    for (int i = 0; i < n; i++)
    {
        // 是否已记录
        int temp = dp[i] == 0 ? MaxCakePriceMemorized(i, priceList, dp) : dp[i];
        result = Math.Max(result, temp + priceList[n - i]);
    }
    dp[n] = result; // 记录f(n)
    return result;
}
```

使用记忆化递归，递归二叉树重叠节点被剪枝。时间复杂度降低至O(n^2^)，包括计算f(2)至f(n-1)共n-1个子问题，使用O(n)时间；计算f(i)需要遍历i-1种子问题组合，使用O(n)时间。

#### 方法三：动态规划

动态规划从底至顶求解f(n)。

``` C#
int MaxCakePrice(int n, int[] priceList)
{
    if (n <= 1) return priceList[n];
    int[] dp = new int[n + 1];
    for (int i = 1; i < n; i++) // 按顺序计算f(1)，...，f(n)
    {
        for (int j = 0; j < i; j++) // 从j种组合中选择最高售价组合作为f(j)
        {
            dp[j] = Math.Max(dp[j], dp[i] + priceList[i - j]);
        }
    }
    return dp[n];
}
```

#### 小结

动态规划通过填表避免了重复计算问题，并通过状态转移方程、初始状态实现对问题的迭代求解。

普遍看来，求最值问题一般都具有重叠子问题和最优子结构特点，因此此类问题比较适合用动态规划解决。

## 动态规划解决框架

若确定给定问题具有重叠子问题和最优子结构，便可使用动态规划求解。总体上看，求解可分为四步：

1. 状态定义：构建问题最优解模型，包括问题**最优解的定义**、有哪些**计算解的自变量**；
2. 初始状态：确定**基础子问题的解**（即已知解），原问题和子问题的解都是以基础子问题的解为起始解，在迭代计算中得到的；
3. 转移方程：确定原问题的解与子问题的解之间的关系是什么，以及使用何种**选择规则**从子问题最优解组合中选出原问题最优解；
4. 返回值：确定应返回的问题的解是什么，即**动态规划在何处停止迭代**。
