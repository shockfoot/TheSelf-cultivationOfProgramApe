# 动画系统

## Legacy动画系统

Legacy动画系统也称旧版动画系统，导入模型之后，可以选择旧版动画系统控制动画，即使用Animation组件控制动画。

Animation编辑器可以编辑物理动画。当场景中物体在项目中完全只起到衬托作用而无交互时，该对象的动画完全可以使用Animation编辑器完成。使用Animation编辑器为对象录制动画片段Animation Clip时，需要先给对象添加Animation组件，然后再打开Animation编辑器创建并录制动画片段，通过曲线Caves控制动画趋势。

Animation编辑器中选择对象的组件并修改指定值、添加关键帧以录制动画，并可以在动画执行过程中需要触发某个方法时添加事件。任何组件以及材质的属性都可以进行动画处理，包括自定义组件的公开变量。

动画片段：

- Wrap Mode动画结束后的处理模式：Default默认（使用动画剪辑中的处理方法）；Once播放一次；Loop循环播放；Ping Pong来回播放；Clamp Forever固定永久（播放到头后永远保持最后一帧）。

Animation组件：

- Animation动画源。
- Animations动画列表：将对象上的动画全部添加在动画列表上。
- Play Automatically是否自动播放。
- Animate Physics物理动画：选择此项，动画可以与物理引擎交互，尤其在`Update`方法中可以使动画正常播放。
- Culling Type剔除类型：Always Animate总是播放动画；Based On Renderers渲染时播放。

脚本控制：

``` C#
// 获取Animation组件
Animation animation = GetComponent<Animation>();
// 播放动画
animation.Play("animationName");
```

## Mecanim动画系统

优点：针对人形角色提供了一种特殊的工作流，包含Avatar的创建和对肌肉的调节；动画重定向的能力可以非常方便地把动画从一个角色模型应用到其他角色模型上；提供了可视化Animator窗口，可以直观地通过动画参数和Transiton等管理各个动画间的过渡。Animator中包含多个Animation，可以自动管理多个动画。

工作流程：模型准备与导入；角色设置；动画应用（动画剪辑、动画控制器、混合树、动画参数）。

模型导入：导入模型的动画如果是完整动画，需要按动作分割成多个动画片段使用。动画或模型以“角色名@动作名”命名。

模型面板参数：

- Scale Factor缩放因子。
- Use File Scale是否使用文件默认缩放因子。
- Mesh Compression网格压缩：低/中/高。
- Read/Write Enabled是否可读可写：会变化的模型要勾选。
- Optimize Mesh是否优化网格：一般布尔值的优化都勾选。
- Import BlendShapes是否导入表情动画。
- Generate Colliders是否生成碰撞器。
- Import Materials是否导入材质。

Rig面板参数：

- Animation Type动画类型：None；Legacy；Generic通用的；Humanoid类人形。
- Avatar Definition骨骼映射：Creat From This Model从当前模型创建；Copy From Other Avatar复制。
- Optiomize Game Objtect是否优化游戏对象。

Animation面板参数：

- Import Animation是否导入动画。
- Anim. Compression动画压缩：值越大越粗糙，值越小越细节。

动画片段参数：

- Start/End开始/结束参数。
- Loop Time是否循环。
- Root Transform Rotation/Position是否冻结旋转/位移：模型动作可能会有旋转/位移，可以根据需要选择。
- Curves动画曲线。
- Events事件。
- Mask遮罩。
- Motion动画片段。

Animator组件：

- Controller动画控制器。
- Avatar谷歌。
- Apply Root Motion应用模型的位移和旋转。
- Update Mode更新方式：Normal；Animate Physics物理交互；Unscaled Time忽略时间缩放。
- Culling Mode剔除模式：Always总是播放动画；Cull Update Transforms剔除动画但不忽略模型位移和旋转；Cull Completely剔除全部。

动画控制器默认三个状态：Any State、Entry和Exit。Entry会默认连接一个动画片段。

每个状态可以设置参数：

- Motion动画。
- Speed速度。
- Mirror镜像。
- Cycle Offset起始帧偏移多少播放。
- Foot IK反向动力学。

动画过渡线参数：

- Transitions：Solo单线通过；Mute暂停。
- Has Exit Time是否有退出时间：当前动画是否会被打断，勾选了将等当前动画播放结束才播放下一个动画。
- 过渡面板：设置动画重叠部分以达到淡入淡出效果。
- Conditions条件：过渡条件。

状态过渡条件只有Float、Int、Bool、Trigger四种。其中Float通过大/小于某值来触发条件，Int通过大/小于、（不）等于某值触发，Bool通过`true`、`false`触发，设置值后不会改变，而Trigger也是Bool类型的，但通过一次后会更改其值。

在脚本中获取Animator组件后，可以通过`SetFloat()`、`SetInteger()`、`SetBool()`、`SetTrigger()`、`GetFloat()`、`GetInteger()`、`GetBool()`、`GetTrigger()`方法按条件名设置/获取相应条件的值。`StringToHash`可以获得字符串对应的Hash I。`GetCurrentAnimatorStateInfo`/`GetNextAnimatorStateInfo`用于获取当前层或下一层动画状态信息。

### 动画事件行为类

通常在动画中添加事件时，将动画事件行为类（AnimatorEventBehaviour）给到策划为动画添加事件，指向已命名的方法，而程序员只需要在其他脚本中注册事件即可。

``` C#
class AnimatorEventBehaviour : MonoBehaviour
{
    public event Action attackHandler;
    
    private void OnAttack()
    {
        if (attackHandler != null)
        {
            attackHandler();
        }
    }
}

class PlayerController : MoneBehaviour
{
    AnimatorEventBehaviour ani;
    
    void Start()
    {
        ani = GetComponentInChild<AnimatorEventBehaviour>();
        ani.attackHandler += Attack;
    }
    
    void Attack
    { }
}
```

### BlendTree混合树

BlendTree相当于一个复合的动画片段，可以作为Mecanim动画状态机中的一个节点。BlendTree的主要作用是把几个类似的动画片段（如向左/右/前跑）合成一个复合的动画片段，因此BlendTree相当于一个动画合成器。

BlendTree在动画编辑器中右键创建，双击进入BlendTree编辑模式。

- Blend Type模式：1D；2D Simple Directional；2D Freeform Directional；2D Freeform Cartesian；Direct。
- Parameter参数。
- Motion动画列表。
  - 参数值。
  - 速度。
  - 镜像。
- Automate Threshold自动设置参数。
- Adjust Time Scale适应时间缩放。

### 层

通过动画控制器的层功能，可以控制角色不同部位的动画并实现不同的逻辑（如边跑边攻击）。

点击`+`添加层，可更改Name，并能通过Weight设置动画权重。默认层中有动画状态机，在新建的层中将需要的动画拖到面板中。

- Weight权重：层权重越大，。
- Mask遮罩：当重叠播放动画时，在Avatar Mask中选择相应的部位。
- Blending混合：Override覆盖（覆盖上一层动画）；Additive增加（在上一层动画上添加当前层动画）。
- IK Pass反向动力学（子节点控制父节点）：`OnAnimatorIK`委托实现。
